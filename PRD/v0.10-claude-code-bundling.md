# v0.10 Claude Code CLI Bundling

[中文版本](../i18n/zh_CN/PRD/v0.10-claude-code-bundling.md)

## Overview

This PRD defines how Claude Code CLI is bundled and managed within ZimaOS-Echo. The goal is to provide a seamless experience where Claude Code CLI is available out-of-the-box while maintaining flexibility for different deployment scenarios.

## Goals

1. **Minimal binary size** - Do not embed CLI by default, keep Echo binary small (~50MB)
2. **Zero-configuration deployment** - CLI is automatically downloaded on first use
3. **Flexible deployment** - Support both embedded and downloaded CLI modes
4. **Version management** - Users can view and update CLI version from settings
5. **Automatic updates** - Optional automatic version checking and updates
6. **System CLI support** - Use existing system-installed CLI if available and validated

## Binary Resolution Order

When resolving the Claude Code CLI binary, the system follows this priority:

1. **Embedded binary** - If embedded for current platform, extract and use
2. **Downloaded binary** - If previously downloaded, use cached version
3. **System PATH** - If allowed and validated, use system-installed CLI
4. **Download from GCS** - Download latest version as fallback

### System CLI Validation

When using a system-installed CLI, the system performs:

1. **Version check** - Execute `claude --version` to get version string
2. **Dry run validation** - Execute `claude --help` to verify it's a real Claude Code CLI
3. **Latest version check** (optional) - If `require_latest` is enabled, verify version matches latest

This ensures only genuine Claude Code CLI binaries are used, preventing security issues from malicious binaries in PATH.

## Bundling Modes

### Mode 1: Download on Demand (Default)

The CLI is downloaded on first use or when explicitly requested.

**Characteristics:**
- Smaller initial binary size (~50MB)
- Requires network on first use
- Always gets the latest CLI version
- Suitable for most deployment scenarios

**Build Command:**
```bash
# Build without embedded CLI (default)
make build
```

### Mode 2: Embedded (Optional)

The Claude Code CLI binary is embedded into the Echo binary at build time.

**Characteristics:**
- Single binary deployment
- No network required at startup
- Larger binary size (~170-220MB depending on platform)
- CLI version fixed at build time

**Build Command:**
```bash
# Build with embedded CLI for current platform only
EMBED_CLAUDE_CODE=true make build

# Build with embedded CLI for specific platform
EMBED_CLAUDE_CODE=true EMBED_PLATFORM=linux-arm64 make build

# Build with all platforms embedded (for distribution)
EMBED_CLAUDE_CODE=true EMBED_ALL_PLATFORMS=true make build
```

## Configuration

### Config File (`config.yaml`)

```yaml
claudecode:
  enabled: true

  # Bundling configuration
  bundling:
    # Mode: "embedded" | "download" | "system" | "auto"
    # - embedded: Use embedded binary only
    # - download: Always download, never use embedded or system
    # - system: Prefer system CLI if available and validated
    # - auto: Use embedded if available, then system, then download (default)
    mode: "auto"

    # System CLI settings
    system:
      allow: true              # Allow using system-installed CLI
      require_latest: false    # Only use system CLI if it's the latest version
      validate: true           # Validate system CLI with dry run before use

    # Auto-update settings
    auto_update:
      enabled: false           # Enable automatic updates
      check_interval: "24h"    # How often to check for updates
      channel: "stable"        # Release channel: "stable" | "beta"

    # Download settings (when mode is "download" or "auto")
    download:
      base_url: "https://storage.googleapis.com/claude-code-dist-86c565f3-f756-42ad-8dfa-d59b1c096819/claude-code-releases"
      cache_dir: ""            # Empty = ~/.local/share/zimaos-echo/claude-code
      verify_checksum: true    # Verify SHA256 checksum after download
      timeout: "5m"            # Download timeout

    # Version pinning (optional)
    version: ""                # Empty = latest, or specific version like "2.1.22"
```

### Environment Variables

| Variable | Description | Default |
|----------|-------------|---------|
| `ECHO_CC_MODE` | Bundling mode override | `auto` |
| `ECHO_CC_VERSION` | Pin to specific version | (latest) |
| `ECHO_CC_AUTO_UPDATE` | Enable auto-update | `false` |
| `ECHO_CC_CACHE_DIR` | Custom cache directory | `~/.local/share/zimaos-echo/claude-code` |
| `ECHO_CC_ALLOW_SYSTEM` | Allow system CLI | `true` |
| `ECHO_CC_REQUIRE_LATEST` | Require latest version for system CLI | `false` |

## Version Management

### Version Information

The system tracks:
- **Embedded version**: Version bundled at build time (if any)
- **Installed version**: Version currently installed/extracted
- **System version**: Version of system-installed CLI (if available)
- **Latest version**: Latest available version from release channel
- **Active version**: Version currently in use

## Build System Changes

### Makefile Updates

```makefile
# Embedding options (default: no embedding)
EMBED_CLAUDE_CODE ?= false
EMBED_PLATFORM ?= $(shell go env GOOS)-$(shell go env GOARCH | sed 's/amd64/x64/')
EMBED_ALL_PLATFORMS ?= false

# Download Claude Code CLI for embedding (only when EMBED_CLAUDE_CODE=true)
download-claude-code:
ifeq ($(EMBED_CLAUDE_CODE),true)
ifeq ($(EMBED_ALL_PLATFORMS),true)
	@$(PROJECT_ROOT)/scripts/download-claude-code.sh --all
else
	@$(PROJECT_ROOT)/scripts/download-claude-code.sh --platform $(EMBED_PLATFORM)
endif
else
	@echo "Skipping Claude Code CLI embedding (EMBED_CLAUDE_CODE=false)"
	@echo "CLI will be downloaded on first use"
	@mkdir -p $(CLAUDE_CODE_DIR)
	@touch $(CLAUDE_CODE_DIR)/.gitkeep
endif
```

### Download Script Updates

```bash
#!/bin/bash
# scripts/download-claude-code.sh

# Parse arguments
PLATFORM=""
ALL_PLATFORMS=false

while [[ $# -gt 0 ]]; do
    case $1 in
        --platform)
            PLATFORM="$2"
            shift 2
            ;;
        --all)
            ALL_PLATFORMS=true
            shift
            ;;
        *)
            shift
            ;;
    esac
done

# If specific platform requested, only download that one
if [ -n "$PLATFORM" ]; then
    PLATFORMS=("$PLATFORM")
elif [ "$ALL_PLATFORMS" = true ]; then
    PLATFORMS=("darwin-arm64" "darwin-x64" "linux-arm64" "linux-x64" "win32-x64")
else
    # Default: current platform only
    PLATFORMS=("$(get_current_platform)")
fi
```

## Security Considerations

1. **Checksum Verification**: Always verify SHA256 checksum after download
2. **HTTPS Only**: Only download from official HTTPS endpoints
3. **Signature Verification**: (Future) Verify binary signatures
4. **Sandboxed Execution**: Run CLI in sandboxed environment
5. **Version Pinning**: Allow pinning to specific versions for stability

## Rollback Strategy

If an update causes issues:

1. **Automatic Rollback**: If CLI fails to start after update, revert to previous version
2. **Manual Rollback**: Users can select previous version from history
3. **Embedded Fallback**: If all else fails, fall back to embedded version

## Non-Functional Requirements

| Requirement | Target |
|-------------|--------|
| Download timeout | < 5 minutes |
| Version check latency | < 2 seconds |
| Binary extraction time | < 5 seconds |
| Settings page load time | < 500ms |
| Update notification delay | < 1 second |
