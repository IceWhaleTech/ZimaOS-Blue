### Supported Document Types

| Type | Extension | Parser |
|------|-----------|--------|
| PDF | `.pdf` | pdfcpu / unipdf |
| Word | `.docx` | unioffice |
| Text | `.txt` | native |
| Markdown | `.md` | native |
| HTML | `.html` | goquery |
| CSV | `.csv` | native |

### Embedding Models

| Model | Dimensions | Notes |
|-------|------------|-------|
| OpenAI text-embedding-3-small | 1536 | Cloud |
| OpenAI text-embedding-3-large | 3072 | Cloud |
| Ollama nomic-embed-text | 768 | Local |
| Ollama mxbai-embed-large | 1024 | Local |

### Vector Database Options

| Database | Pros | Cons |
|----------|------|------|
| SQLite-vec | Embedded, simple | Limited scale |
| Qdrant | Feature-rich, fast | Separate service |
| Milvus | Enterprise-grade | Complex setup |
| Chroma | Python-native | Not Go |
