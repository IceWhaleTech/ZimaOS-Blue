## Configuration

### New Config Options
```yaml
# config.yaml additions for v0.4

# Plugin system
plugins:
  enabled: true
  directory: "./plugins"
  auto_load: true
  wasm_enabled: false
  wasm_memory_limit_mb: 64

# Skill Hub
skills:
  enabled: true
  manifest_dir: "./skills"
  builtin:
    weather: true
    search: true
    calculator: true

# Authentication
auth:
  enabled: true
  jwt:
    secret: "${JWT_SECRET}"
    expiration: "24h"
    refresh_expiration: "168h"
  api_keys:
    enabled: true
    max_per_user: 10

# RBAC
rbac:
  enabled: true
  default_role: "user"
  roles:
    - name: admin
      permissions: ["*"]
    - name: user
      permissions: ["chat", "skills.execute"]
    - name: readonly
      permissions: ["chat.read", "skills.list"]
```

## API Endpoints (New)

### Authentication
| Method | Path | Description |
|--------|------|-------------|
| POST | `/api/v1/auth/login` | User login |
| POST | `/api/v1/auth/logout` | User logout |
| POST | `/api/v1/auth/refresh` | Refresh token |
| GET | `/api/v1/auth/me` | Get current user |

### API Keys
| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/v1/apikeys` | List API keys |
| POST | `/api/v1/apikeys` | Create API key |
| DELETE | `/api/v1/apikeys/:id` | Delete API key |

### Plugins
| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/v1/plugins` | List plugins |
| GET | `/api/v1/plugins/:id` | Get plugin details |
| POST | `/api/v1/plugins/:id/enable` | Enable plugin |
| POST | `/api/v1/plugins/:id/disable` | Disable plugin |
| PUT | `/api/v1/plugins/:id/config` | Update plugin config |

### Skills
| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/v1/skills` | List skills |
| GET | `/api/v1/skills/:id` | Get skill details |
| POST | `/api/v1/skills/:id/execute` | Execute skill |
