## Release Notes Draft

### v0.10.8 - Skill Store Improvements

**New Features**:
- Featured Skills: Curated list of popular skills as fallback when API fails
- Local Skill Discovery: Automatically find skills in `~/.claude/skills/`
- Install from URL: Add skills directly from GitHub or any URL
- Skill Verification: New endpoint to verify skill visibility to CC CLI
- Improved Search: Better multi-language search support

**Improvements**:
- Hybrid approach: Keep ClawHub/GitHub API with featured skills fallback
- Better error handling when external APIs fail
- New API endpoints for local skill management

**API Changes**:
- `GET /skill-store/featured` - Get featured skills
- `GET /skills/local` - List local skills
- `POST /skills/local/scan` - Scan local skills directory
- `GET /skills/verify/:id` - Verify skill visibility
- `POST /skill-store/install-url` - Install from URL
