# v0.10.16 Speech Module Checklist

## Overview
This release adds Speech-to-Text (ASR) and Text-to-Speech (TTS) capabilities using sherpa-onnx with local ONNX models. Features include model downloading with resume support, model switching, and walkie-talkie mode.

**Existing Implementation**:
- TTS: `server/internal/tts/sherpa.go`, `server/internal/tts/sherpa_download.go`
- ASR: `server/internal/stt/sherpa.go`, `server/internal/stt/sherpa_download.go`
- Downloaded Model: `server/data/sherpa-tts/kokoro-en-v0_19/`
