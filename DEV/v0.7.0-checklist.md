# v0.7.0 Implementation Checklist

[中文版本](../i18n/zh_CN/DEV/v0.7.0-checklist.md)

This checklist tracks the implementation progress of v0.7.0 (Security Enhancement).

## Goal
Complete security mechanism - implement OIDC provider, local user management, password authentication, multi-factor authentication, audit logging, and sandbox execution environment.

- [x] Built-in OIDC Provider fully functional

- [x] Password authentication using Argon2id
- [x] TOTP-based multi-factor authentication working
- [x] Comprehensive audit logging system

- [ ] Unit tests for all security modules

## Configuration

### New Config Options
```yaml
# config.yaml additions for v0.7

# Security configuration
security:
  # OIDC Provider
  oidc:
    enabled: true
    issuer: "https://your-domain.com"
    signing_key_path: "./keys/oidc.key"
    signing_key_rotation_days: 90
    access_token_ttl: 1h
    refresh_token_ttl: 720h  # 30 days
    authorization_code_ttl: 10m
    clients:
      - client_id: "web-app"
        client_secret: ""  # Public client
        redirect_uris:
          - "http://localhost:3000/callback"
        allowed_scopes:
          - "openid"
          - "profile"
          - "email"

  # User Management
  users:
    allow_registration: false
    require_email_verification: false
    default_role: "user"

  # Password Policy
  password:
    min_length: 12
    require_uppercase: true
    require_lowercase: true
    require_number: true
    require_special: true
    history_count: 5
    expiration_days: 0  # 0 = never expires
    lockout_threshold: 5
    lockout_duration: 15m

  # MFA
  mfa:
    enabled: true
    required: false  # Require MFA for all users
    issuer: "ZimaOS-Echo"
    recovery_codes_count: 8

  # Audit
  audit:
    enabled: true
    retention_days: 90
    log_request_body: false
    log_response_body: false
    excluded_paths:
      - "/health"
      - "/metrics"

  # Sandbox
  sandbox:
    enabled: true
    default_timeout: 30s
    max_timeout: 5m
    memory_limit: 256MB
    cpu_limit: 1.0  # 1 CPU core
    process_limit: 10
    network_enabled: false
```

## Security Considerations

1. **Password Storage**: Use Argon2id with secure parameters
2. **Token Security**: Short-lived access tokens, secure refresh token rotation
3. **MFA Security**: Rate limit TOTP attempts, secure recovery codes
4. **OIDC Security**: PKCE required, strict redirect URI validation
5. **Audit Integrity**: Append-only logs, tamper detection
6. **Sandbox Security**: Defense in depth, minimal privileges
