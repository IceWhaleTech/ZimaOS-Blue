## Configuration

### New Config Options
```yaml
# config.yaml additions for v0.5

# Metrics
metrics:
  enabled: true
  endpoint: "/metrics"
  include_runtime: true
  include_http: true
  include_llm: true

# Profiling
profiling:
  enabled: false  # Enable only for debugging
  endpoint_prefix: "/debug/pprof"
  auth_required: true

# Hot reload
config:
  hot_reload: true
  watch_interval_ms: 1000
  validate_before_apply: true

# Resilience
resilience:
  circuit_breaker:
    enabled: true
    threshold: 5
    timeout_seconds: 30
  timeout:
    default_ms: 30000
    llm_ms: 120000

# Backup
backup:
  enabled: true
  schedule: "0 2 * * *"  # Daily at 2 AM
  retention_days: 7
  path: "./backups"
```

| Method | Path | Description |
|--------|------|-------------|

| GET | `/api/v1/backup` | List backups |
