## Technical Reference

### Go Library Build Commands

```bash
# ARM64
CGO_ENABLED=1 GOOS=darwin GOARCH=arm64 \
  go build -buildmode=c-archive \
  -o libecho_arm64.a ./server/cmd/echolib

# x64
CGO_ENABLED=1 GOOS=darwin GOARCH=amd64 \
  go build -buildmode=c-archive \
  -o libecho_x64.a ./server/cmd/echolib

# Universal binary
lipo -create -output libecho.a libecho_arm64.a libecho_x64.a
```

### DMG Compression Command

```bash
create-dmg \
  --volname "ZimaOS Echo" \
  --format ULMO \
  "ZimaOS-Echo_${VERSION}_${ARCH}.dmg" \
  "target/release/bundle/macos/ZimaOS Echo.app"
```

## Notes

- macOS: CGO库方式，单进程，启动快
- Windows: Sidecar方式，独立进程
- 不使用UPX压缩二进制文件
- DMG使用LZMA压缩，安装后启动快

## Build Commands

```bash
# macOS: Build with CGO library
make build-echo-lib-macos    # Build Go static library
make tauri-build-macos-cgo   # Build complete Tauri app

# Or use the build script (recommended)
cd tauri-app && ./build.sh

# Windows: Build with sidecar
make tauri-sidecar           # Build Go sidecar binary
make tauri-build             # Build Tauri app
```
