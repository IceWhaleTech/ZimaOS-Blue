## Phase 1: Content Detection & Segmentation (P0) ✅

- [x] 1.1 Add `ContentType` enum to `bm25.go` (Code, Doc, Log, Data, Unknown)
- [x] 1.2 Extend `DetectContentType()` in `detector.go` — classify code vs doc vs log vs data
- [x] 1.3 Implement `SegmentizeParagraphs()` in `paragraph.go` — heading + paragraph splitting
- [x] 1.4 Implement `SegmentizeLogs()` in `paragraph.go` — timestamp/blank-line grouping
- [x] 1.5 Implement `SegmentizeData()` in `paragraph.go` — JSON/YAML top-level key splitting
- [x] 1.6 Implement `AutoSegmentize()` — dispatch by ContentType
- [x] 1.7 Add non-code `SegmentKind` values (Paragraph, Heading, Sentence, LogGroup, DataKey)

## Phase 2: Unified Tokenizer (P0) ✅

- [x] 2.1 `codeTokenize()` stays in `bm25.go` (no move needed — already shared)
- [x] 2.2 Implement `textTokenize()` in `tokenizer.go` with stopword removal
- [x] 2.3 Add English stopword list (~50 common words)
- [x] 2.4 Implement `UnifiedTokenize(text, ContentType)` dispatcher

## Phase 3: IRPruner Backend (P0) ✅

- [x] 3.1 Implement `IRPruner` struct in `ir_pruner.go`
- [x] 3.2 Wire content detection → segmentation → BM25 → boost → TopK pipeline
- [x] 3.3 Add heading boost (1.2x) for non-code heading segments
- [x] 3.4 Add position boost (1.1x) for first/last 10% of non-code content
- [x] 3.5 Update `PruneRequest` — add `Content` field (keep `Code` for backward compat)
- [x] 3.6 Update `PruneResponse` — add `ContentType` + `PrunedContent` fields
- [x] 3.7 Update `NewBackend()` factory — add `"ir"`, `"code"` modes
- [x] 3.8 Backward compat: `"local"` and `"bm25"` still work, `"remote"` maps to `"code"`

## Phase 4: Disk Cache (P1) ✅

- [x] 4.1 Implement `DiskCache` in `cache_disk.go` — SQLite-backed (reuses proxy's modernc.org/sqlite driver)
- [x] 4.2 Add TTL-based expiration for disk cache entries
- [x] 4.3 Implement `Cleanup()` for expired entry removal
- [x] 4.4 Thread-safe operations with `sync.RWMutex`
- [x] 4.5 No-op fallback when dbPath is empty or invalid
