## Notes

- Templates stored in `data/formfiller/templates.json`
- Patterns stored in `data/formfiller/patterns.json`
- Site mappings stored in `data/formfiller/sites/<domain>.json`
- Password values are NEVER logged or stored
- LLM field classification sends only field metadata, not values
