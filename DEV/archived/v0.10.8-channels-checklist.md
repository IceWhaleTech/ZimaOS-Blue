## API Reference

### Connection Test Endpoint

```
POST /api/setup/test-connection
Content-Type: application/json

{
  "type": "telegram|discord|slack|teams|mattermost|bluebubbles|zalo|...",
  "config": {
    // Channel-specific configuration
  }
}

Response (Success):
{
  "success": true,
  "messageKey": "testSuccess",
  "data": {
    "bot_name": "MyBot",
    "bot_id": "180789",
    // Additional info from API
  }
}

Response (Failure):
{
  "success": false,
  "messageKey": "invalidToken|connectionFailed|...",
  "error": "Detailed error message"
}
```

### Channel Configuration

#### Teams
```json
{
  "app_id": "Microsoft App ID",
  "app_password": "Microsoft App Password",
  "tenant_id": "Azure Tenant ID (optional, for single-tenant)",
  "allowed_teams": ["team-id-1", "team-id-2"],
  "allowed_users": ["user-id-1"]
}
```

#### Mattermost
```json
{
  "server_url": "https://mattermost.example.com",
  "bot_token": "Bot Access Token",
  "allowed_channels": ["channel-id-1"],
  "allowed_users": ["user-id-1"]
}
```

#### BlueBubbles
```json
{
  "server_url": "http://localhost:1234",
  "password": "BlueBubbles Server Password",
  "allowed_chats": ["chat-guid-1"]
}
```

#### Zalo
```json
{
  "oa_id": "Official Account ID",
  "access_token": "OA Access Token",
  "refresh_token": "OA Refresh Token",
  "app_id": "Zalo App ID",
  "secret_key": "Zalo Secret Key"
}
```
