## Overview

This archive records the v0.10.36 session as a runtime-convergence release rather than a feature-expansion release.

The work was driven by five overlapping planning tracks:

- Runtime convergence and route-layer consolidation
- Harness as a real runtime control plane rather than only a benchmark surface
- Deep Research runtime alignment, while deferring the full iterative vNext loop
- Skill and gateway contract groundwork, while deferring the high-risk tool-surface migration
- External agent and operator surface preparation, without pulling those runtimes into the main chat lane

The release rule for this version was simple:

- Keep current chat, agent, harness, deep research, subagent, approval, and memory behavior externally stable
- Spend the cycle on internal boundaries, shared contracts, and regression coverage
- Avoid risky schema migrations and protocol-breaking cutovers
- Make the route layer thin again
- Push orchestration toward a single runtime bundle and explicit lane bindings
- Keep canonical `skill` and `tool` identifiers underscore-based
