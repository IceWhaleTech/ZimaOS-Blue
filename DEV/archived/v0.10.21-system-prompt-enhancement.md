### 3. Silent Reply Mechanism ✅
**File**: `server/internal/claudecode/systemprompt.go:151-169`

```go
func (b *SystemPromptBuilder) buildSilentReplyGuidance() string {
    // When you have nothing to say, respond with ONLY: [SILENT_REPLY]
    // Rules:
    // - Must be ENTIRE message
    // - Never append to actual response
    // - Never wrap in markdown/code blocks
}
```

**Purpose**:
- Allows AI to acknowledge without generating unnecessary content
- Prevents empty or filler responses
- Reduces token waste

**Use Cases**:
- Background task completion acknowledgments
- Tool execution confirmations
- Status updates without user-facing content
