## Overview

v0.10.38 is a follow-up release after the broader runtime and operator work already recorded in v0.10.37.

This version does not reopen the main architecture. Instead, it consolidates the next product-facing layer that landed immediately after that runtime cycle:

- GitHub-backed repository and skill-market flows became more complete
- Tool registration and compatibility behavior became more explicit and more testable
- Agentcore Runner settings and context-pack details became easier to inspect and operate
- Skill Store risk signals, marketplace labels, and localization coverage were tightened
- Legacy management-skill naming and stale locale surfaces were normalized
- The web shell picked up another small navigation and viewport polish pass

The release intent for v0.10.38 is therefore straightforward:

- Keep the runtime and public control-plane behavior stable
- Fold recent additive operator and catalog improvements into one archived release record
- Improve settings, storefront, localization, and shell ergonomics without starting another large migration
- Keep version surfaces aligned across server, web, desktop, and installer metadata

## Why This Version Exists

After v0.10.37, the remaining work was less about core runtime shape and more about the operator and storefront experience around it.

At the start of this window:

- GitHub repository-backed flows still needed a cleaner end-to-end story in the marketplace and registration path
- Agentcore Runner and context-pack work existed, but the settings and visibility layer still needed another consolidation pass
- Skill Store security metadata existed, but the visual severity treatment and localization coverage were not yet consistent enough
- Legacy management-skill naming still leaked into parts of the product and locale surface
- The shell still had a few low-risk navigation and viewport polish opportunities

v0.10.38 exists to close that gap without turning a focused product follow-up into another architecture release.
