## Configuration

### New Config Options
```yaml
# config.yaml additions for v0.3

# Resource limits
resources:
  max_memory_mb: 512
  max_cpu_percent: 50
  max_open_files: 65536
  max_goroutines: 10000
  gc_percent: 100

# Cgroup v2 configuration (Linux only)
cgroup:
  enabled: false
  cgroup_root: "/sys/fs/cgroup"
  cgroup_name: "zimaos-echo"
  io:
    enabled: false
    read_bps: 0           # Max read bytes/sec (0 = unlimited)
    write_bps: 0          # Max write bytes/sec (0 = unlimited)
    read_iops: 0          # Max read IOPS (0 = unlimited)
    write_iops: 0         # Max write IOPS (0 = unlimited)
    devices: []           # Device major:minor list
  memory:
    enabled: false
    max_bytes: 0
    high_bytes: 0
    swap_max_bytes: 0
  cpu:
    enabled: false
    max_percent: 0
    weight: 100

# File watcher
watcher:
  enabled: false
  paths:
    - /data/watch
  events:
    - create
    - modify
  recursive: true
  debounce_ms: 100

# Task scheduler
scheduler:
  enabled: true
  max_concurrent: 10
  persistence: true
  db_path: "./data/scheduler.db"

# Worker pools
workers:
  io_pool_size: 4
  compute_pool_size: 8
```

## Docker Commands

### Build
```bash
# Build image
docker build -t zimaos-echo:latest -f deploy/docker/Dockerfile .

# Build multi-arch
docker buildx build --platform linux/amd64,linux/arm64 -t zimaos-echo:latest .
```

### Run
```bash
# Run with docker
docker run -d \
  --name zimaos-echo \
  -p 8080:8080 \
  -v ./data:/app/data \
  -v ./config.yaml:/app/config.yaml \
  zimaos-echo:latest

# Run with docker-compose
docker-compose up -d
```

---

## systemd Commands

```bash
# Install service
sudo cp deploy/systemd/zimaos-echo.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable zimaos-echo
sudo systemctl start zimaos-echo

# Check status
sudo systemctl status zimaos-echo
sudo journalctl -u zimaos-echo -f
```
