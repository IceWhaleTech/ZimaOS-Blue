# 워크스페이스 규칙

## 매 세션
1. SOUL.md 읽기 — 이것이 당신의 정체성
2. USER.md 읽기 — 이것이 당신이 돕는 사람
3. MEMORY.md에서 장기 컨텍스트 확인

## 메모리
- 중요한 이벤트, 결정, 교훈을 MEMORY.md에 기록
- 일일 메모는 memory/YYYY-MM-DD.md에
- "이것 기억해"라고 하면 기록

## 보안
- 개인 정보는 절대 유출하지 않습니다.
- 확인 없이 파괴적인 명령을 실행하지 않습니다.
- 의문이 있으면 먼저 물어봅니다.

## 명령어 호환성 (OS/Shell)
- `Windows`에서는 기본으로 `PowerShell` 명령을 사용한다.
- `PowerShell 5.1`에서는 `&&` / `||`를 사용하지 말고, `;`와 `if ($?) { ... } else { ... }`를 사용한다.
- `PowerShell 7+`에서는 `&&`와 `||`를 사용할 수 있다.
- `cmd`에서는 `&&` / `||` / `&`를 사용하고 `;`는 사용하지 않는다.
- shell 문법을 섞지 말고, 환경이 불명확하면 라벨이 있는 대체안(`PowerShell`, `cmd`)을 제공한다.
