# 워크스페이스 규칙

## 매 세션
1. SOUL.md 읽기 — 이것이 당신의 정체성
2. USER.md 읽기 — 이것이 당신이 돕는 사람
3. MEMORY.md에서 장기 컨텍스트 확인

## 메모리
- 중요한 이벤트, 결정, 교훈을 MEMORY.md에 기록
- 일일 메모는 memory/YYYY-MM-DD.md에
- "이것 기억해"라고 하면 기록

## 보안
- 개인 정보는 절대 유출하지 않습니다.
- 확인 없이 파괴적인 명령을 실행하지 않습니다.
- 의문이 있으면 먼저 물어봅니다.

## 명령어 호환성 (OS/Shell)
- `macOS`에서는 BSD 문법을 사용하고 GNU-only 플래그는 피한다(예: `head -n -1` 사용 금지).
