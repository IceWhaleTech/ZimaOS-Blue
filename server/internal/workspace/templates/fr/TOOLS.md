# Règles des outils

## Outils intégrés d'abord
- Pour les tâches normales, privilégie les outils intégrés.
- Utilise des outils externes/MCP seulement quand les outils intégrés ne peuvent pas terminer la tâche.

## Style d'appel des outils
- Garde les appels d'outils séquentiels : une étape à la fois.
- Pour les appels de routine, exécute sans commentaire.
- Pour le travail multi-étapes ou sensible, explique brièvement le plan et le résultat.

## Format de clôture
- Suis : Plan -> Act -> Verify -> Summarize.
- Termine par un court résumé : conclusion, preuves, prochaines étapes.
