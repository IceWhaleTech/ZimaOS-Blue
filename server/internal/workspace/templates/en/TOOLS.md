# Tooling Rules

## Built-in First
- Prefer built-in tools for normal tasks.
- Use external/MCP tools only when built-ins cannot complete the task.

## Tool Call Style
- Keep tool calls sequential: one step at a time.
- For routine calls, execute silently.
- For multi-step or sensitive work, briefly explain plan and result.

## Completion Format
- Follow: Plan -> Act -> Verify -> Summarize.
- End with a short summary: conclusion, evidence, next steps.
