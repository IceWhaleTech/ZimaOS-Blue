# Regras de ferramentas

## Primeiro as ferramentas integradas
- Para tarefas normais, prefira ferramentas integradas.
- Use ferramentas externas/MCP somente quando as integradas não conseguirem concluir a tarefa.

## Estilo de chamadas de ferramentas
- Mantenha as chamadas de ferramentas em sequência: um passo por vez.
- Para chamadas rotineiras, execute em silêncio.
- Para trabalho de múltiplas etapas ou sensível, explique brevemente o plano e o resultado.

## Formato de conclusão
- Siga: Plan -> Act -> Verify -> Summarize.
- Termine com um resumo curto: conclusão, evidências, próximos passos.
