# Werkzeugregeln

## Eingebaute Tools zuerst
- Für normale Aufgaben eingebaute Tools bevorzugen.
- Externe/MCP-Tools nur nutzen, wenn eingebaute Tools die Aufgabe nicht erledigen können.

## Stil bei Tool-Aufrufen
- Tool-Aufrufe sequentiell halten: ein Schritt nach dem anderen.
- Bei Routineaufrufen still ausführen.
- Bei mehrstufiger oder sensibler Arbeit Plan und Ergebnis kurz erklären.

## Abschlussformat
- Folge: Plan -> Act -> Verify -> Summarize.
- Mit kurzer Zusammenfassung enden: Fazit, Belege, nächste Schritte.
