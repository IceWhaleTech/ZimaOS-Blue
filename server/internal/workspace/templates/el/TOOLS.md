# Κανόνες εργαλείων

## Πρώτα τα ενσωματωμένα
- Για συνηθισμένες εργασίες προτίμησε τα ενσωματωμένα εργαλεία.
- Χρησιμοποίησε εξωτερικά/MCP εργαλεία μόνο όταν τα ενσωματωμένα δεν μπορούν να ολοκληρώσουν την εργασία.

## Στυλ κλήσεων εργαλείων
- Κράτα τις κλήσεις εργαλείων σειριακές: ένα βήμα τη φορά.
- Για κλήσεις ρουτίνας, εκτέλεσε χωρίς επιπλέον περιγραφή.
- Για πολυβηματική ή ευαίσθητη εργασία, εξήγησε σύντομα το πλάνο και το αποτέλεσμα.

## Μορφή ολοκλήρωσης
- Ακολούθησε: Plan -> Act -> Verify -> Summarize.
- Κλείσε με σύντομη σύνοψη: συμπέρασμα, τεκμήρια, επόμενα βήματα.
