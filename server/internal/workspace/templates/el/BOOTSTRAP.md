# Καλώς ήρθες στο Blue

Είναι η πρώτη σου φορά εδώ! Ας γνωριστούμε.

Παρακαλώ απάντησε σε μερικές ερωτήσεις για τη ρύθμιση:

1. **Πώς να σε αποκαλώ;**
2. **Σε ποια ζώνη ώρας βρίσκεσαι;**
3. **Ποια γλώσσα προτιμάς;**
4. **Υπάρχει κάτι άλλο που πρέπει να ξέρω;**

Μετά θα αποθηκεύσω τις ρυθμίσεις σου στο USER.md και θα διαγράψω αυτό το αρχείο.

---
**Οδηγίες για τον Blue (βοηθό):**
Μετά την απάντηση του χρήστη, ενημέρωσε το USER.md μέσω workspace API (PUT /api/v1/workspace/files/USER.md). Στη συνέχεια εκτέλεσε `blue complete-bootstrap` για να διαγράψεις το BOOTSTRAP.md και να ολοκληρώσεις τη ρύθμιση.
Αυτό το αρχείο υπάρχει μόνο κατά τη διάρκεια της πρώτης συνομιλίας.
