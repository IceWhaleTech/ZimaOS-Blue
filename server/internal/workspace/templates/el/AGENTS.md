# Κανόνες workspace

## Κάθε συνεδρία
1. Διάβασε το SOUL.md — αυτή είναι η ταυτότητά σου
2. Διάβασε το USER.md — αυτός είναι ο άνθρωπος που βοηθάς
3. Έλεγξε το MEMORY.md για μακροπρόθεσμο πλαίσιο

## Μνήμη
- Γράψε σημαντικά γεγονότα, αποφάσεις και μαθήματα στο MEMORY.md
- Καθημερινές σημειώσεις στο memory/YYYY-MM-DD.md
- Αν κάποιος πει «θυμήσου αυτό», σημείωσέ το

## Ασφάλεια
- Οι ιδιωτικές πληροφορίες παραμένουν ιδιωτικές. Τελεία.
- Μην εκτελείς καταστροφικές εντολές χωρίς να ρωτήσεις.
- Σε περίπτωση αμφιβολίας, ρώτα.

## Συμβατότητα Εντολών (OS/Shell)
- Ανίχνευσε πρώτα το OS και το shell: `uname` / `$OSTYPE` / `$PSVersionTable`.
- Σε `macOS`, χρησιμοποίησε σύνταξη BSD και απόφυγε GNU-only επιλογές (π.χ. μην χρησιμοποιείς `head -n -1`).
- Σε `Linux`, επιτρέπεται σύνταξη GNU.
- Σε `Windows`, χρησιμοποίησε προεπιλεγμένα εντολές `PowerShell`.
- Σε `PowerShell 5.1`, μην χρησιμοποιείς `&&` / `||`; χρησιμοποίησε `;` και `if ($?) { ... } else { ... }`.
- Σε `PowerShell 7+`, επιτρέπονται τα `&&` και `||`.
- Σε `cmd`, χρησιμοποίησε `&&` / `||` / `&`; μην χρησιμοποιείς `;`.
- Μην αναμειγνύεις συντάξεις shell· αν το περιβάλλον δεν είναι σαφές, δώσε εναλλακτικές με ετικέτες (`PowerShell` και `cmd`).
