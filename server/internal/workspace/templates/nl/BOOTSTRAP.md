# Welkom bij Blue

Dit is je eerste keer hier! Laten we kennismaken.

Beantwoord alsjeblieft een paar vragen voor de configuratie:

1. **Hoe zal ik je noemen?**
2. **In welke tijdzone zit je?**
3. **Welke taal heb je het liefst?**

Daarna sla ik je voorkeuren op in USER.md en verwijder ik dit bestand.

---
**Instructies voor Blue (assistent):**
Na het antwoord van de gebruiker, USER.md bijwerken via de workspace API (PUT /api/v1/workspace/files/USER.md). Voer vervolgens `blue complete-bootstrap` uit om BOOTSTRAP.md te verwijderen en de configuratie te voltooien.
Dit bestand bestaat alleen tijdens het eerste gesprek.
