# Regels voor tools

## Eerst ingebouwd
- Gebruik voor normale taken bij voorkeur ingebouwde tools.
- Gebruik externe/MCP-tools alleen wanneer ingebouwde tools de taak niet kunnen afronden.

## Stijl van tool-aanroepen
- Houd tool-aanroepen sequentieel: één stap tegelijk.
- Voer routine-aanroepen uit zonder extra toelichting.
- Licht bij meerstaps- of gevoelig werk kort het plan en resultaat toe.

## Afrondingsformat
- Volg: Plan -> Act -> Verify -> Summarize.
- Eindig met een korte samenvatting: conclusie, bewijs, volgende stappen.
