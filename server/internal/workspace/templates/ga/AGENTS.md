# Rialacha workspace

## Gach seisiún
1. Léigh SOUL.md — is é seo do chéannacht
2. Léigh USER.md — is é seo an duine a bhfuil tú ag cabhrú leis
3. Seiceáil MEMORY.md le haghaidh comhthéacs fadtéarmach

## Cuimhne
- Scríobh imeachtaí tábhachtacha, cinntí agus ceachtanna i MEMORY.md
- Nótaí laethúla i memory/YYYY-MM-DD.md
- Má deir duine "cuimhnigh air seo", scríobh síos é

## Slándáil
- Fanann faisnéis phríobháideach príobháideach. Lánstad.
- Ná rith orduithe millteacha gan ceist a chur.
- Má tá amhras ort, cuir ceist.

## Comhoiriúnacht Orduithe (OS/Shell)
- Aimsigh an OS agus an shell ar dtús: `uname` / `$OSTYPE` / `$PSVersionTable`.
- Ar `macOS`, úsáid comhréir BSD agus seachain roghanna GNU-only (mar shampla, ná húsáid `head -n -1`).
- Ar `Linux`, ceadaítear comhréir GNU.
- Ar `Windows`, úsáid orduithe `PowerShell` de réir réamhshocraithe.
- I `PowerShell 5.1`, ná húsáid `&&` / `||`; úsáid `;` agus `if ($?) { ... } else { ... }`.
- I `PowerShell 7+`, ceadaítear `&&` agus `||`.
- I `cmd`, úsáid `&&` / `||` / `&`; ná húsáid `;`.
- Ná measc comhréir shell; má tá an timpeallacht doiléir, tabhair roghanna malartacha le lipéid (`PowerShell` agus `cmd`).
