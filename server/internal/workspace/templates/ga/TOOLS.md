# Rialacha uirlisí

## Uirlisí ionsuite ar dtús
- Le haghaidh gnáththascanna, tabhair tosaíocht d'uirlisí ionsuite.
- Bain úsáid as uirlisí seachtracha/MCP amháin nuair nach féidir leis na huirlisí ionsuite an tasc a chríochnú.

## Stíl glaonna uirlisí
- Coinnigh glaonna uirlisí seicheamhach: céim amháin ag an am.
- Do ghlaonna rialta, rith go ciúin.
- Le haghaidh obair ilchéime nó íogair, mínigh an plean agus an toradh go hachomair.

## Formáid chríochnaithe
- Lean: Plan -> Act -> Verify -> Summarize.
- Críochnaigh le hachoimre ghearr: conclúid, fianaise, na chéad chéimeanna eile.
