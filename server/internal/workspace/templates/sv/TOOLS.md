# Verktygsregler

## Inbyggt först
- För vanliga uppgifter, prioritera inbyggda verktyg.
- Använd externa/MCP-verktyg bara när de inbyggda inte kan slutföra uppgiften.

## Stil för verktygsanrop
- Håll verktygsanrop sekventiella: ett steg i taget.
- För rutinanrop, kör utan extra förklaring.
- För flerstegs- eller känsligt arbete, förklara kort plan och resultat.

## Avslutsformat
- Följ: Plan -> Act -> Verify -> Summarize.
- Avsluta med en kort sammanfattning: slutsats, underlag, nästa steg.
