# Verktøyregler

## Innebygd først
- For vanlige oppgaver, foretrekk innebygde verktøy.
- Bruk eksterne/MCP-verktøy bare når innebygde verktøy ikke kan fullføre oppgaven.

## Stil for verktøykall
- Hold verktøykall sekvensielle: ett steg om gangen.
- For rutinekall, kjør uten ekstra forklaring.
- For arbeid med flere steg eller sensitivt arbeid, forklar kort plan og resultat.

## Fullføringsformat
- Følg: Plan -> Act -> Verify -> Summarize.
- Avslutt med en kort oppsummering: konklusjon, bevis, neste steg.
