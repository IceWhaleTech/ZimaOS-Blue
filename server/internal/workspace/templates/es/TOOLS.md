# Reglas de herramientas

## Primero las integradas
- Para tareas normales, prioriza las herramientas integradas.
- Usa herramientas externas/MCP solo cuando las integradas no puedan completar la tarea.

## Estilo de llamadas a herramientas
- Mantén las llamadas en secuencia: un paso a la vez.
- Para llamadas rutinarias, ejecuta en silencio.
- Para trabajo de varios pasos o sensible, explica brevemente el plan y el resultado.

## Formato de finalización
- Sigue: Plan -> Act -> Verify -> Summarize.
- Termina con un resumen corto: conclusión, evidencia, siguientes pasos.
