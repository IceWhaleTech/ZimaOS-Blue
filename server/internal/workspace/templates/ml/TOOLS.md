# ഉപകരണ ഉപയോഗ നിയമങ്ങൾ

## ആദ്യം ബിൽറ്റ്-ഇൻ ഉപകരണങ്ങൾ
- സാധാരണ ജോലികൾക്ക് ബിൽറ്റ്-ഇൻ ഉപകരണങ്ങൾ മുൻഗണന നൽകുക.
- ബിൽറ്റ്-ഇൻ ഉപകരണങ്ങൾ കൊണ്ട് ജോലി പൂർത്തിയാക്കാൻ കഴിയാത്തപ്പോൾ മാത്രം പുറം/MCP ഉപകരണങ്ങൾ ഉപയോഗിക്കുക.

## ഉപകരണ കോൾ ശൈലി
- ഉപകരണ കോൾകൾ ക്രമമായി നടത്തുക: ഓരോ തവണയും ഒരു ഘട്ടം.
- പതിവ് കോൾകൾക്ക് അധിക വിവരണം ഇല്ലാതെ പ്രവർത്തിപ്പിക്കുക.
- ബഹുഘട്ടമോ സെൻസിറ്റീവായ ജോലിയോ ആണെങ്കിൽ, പദ്ധതിയും ഫലവും ചുരുക്കത്തിൽ വിശദീകരിക്കുക.

## പൂർത്തിയാക്കൽ ഫോർമാറ്റ്
- ഇത് പിന്തുടരുക: Plan -> Act -> Verify -> Summarize.
- അവസാനം ചെറിയൊരു സംഗ്രഹം നൽകുക: നിഗമനം, തെളിവുകൾ, അടുത്ത ചുവടുകൾ.
