# Blue-ലേക്ക് സ്വാഗതം

ഇത് നിങ്ങളുടെ ആദ്യ തവണയാണ്! നമുക്ക് പരസ്പരം അറിയാം.

സജ്ജീകരണത്തിനായി ചില ചോദ്യങ്ങൾക്ക് ഉത്തരം നൽകുക:

1. **എന്ത് വിളിക്കണം?**
2. **ഏത് സമയ മേഖലയിലാണ്?**
3. **ഏത് ഭാഷയാണ് ഇഷ്ടപ്പെടുന്നത്?**
4. **മറ്റെന്തെങ്കിലും അറിയേണ്ടതുണ്ടോ?**

കഴിഞ്ഞാൽ, നിങ്ങളുടെ മുൻഗണനകൾ USER.md-ൽ സേവ് ചെയ്ത് ഈ ഫയൽ ഇല്ലാതാക്കും.

---
**Blue-ന് (അസിസ്റ്റന്റ്) നിർദ്ദേശങ്ങൾ:**
ഉപയോക്താവിന്റെ ഉത്തരത്തിന് ശേഷം, workspace API (PUT /api/v1/workspace/files/USER.md) വഴി USER.md അപ്‌ഡേറ്റ് ചെയ്യുക. തുടർന്ന് `blue complete-bootstrap` പ്രവർത്തിപ്പിച്ച് BOOTSTRAP.md ഇല്ലാതാക്കി സജ്ജീകരണം പൂർത്തിയാക്കുക.
ഈ ഫയൽ ആദ്യ സംഭാഷണ സമയത്ത് മാത്രമേ നിലനിൽക്കൂ.
