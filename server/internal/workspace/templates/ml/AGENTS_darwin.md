# Workspace നിയമങ്ങൾ

## ഓരോ സെഷനും
1. SOUL.md വായിക്കുക — ഇത് നിങ്ങളുടെ ഐഡന്റിറ്റിയാണ്
2. USER.md വായിക്കുക — ഇത് നിങ്ങൾ സഹായിക്കുന്ന വ്യക്തിയാണ്
3. ദീർഘകാല സന്ദർഭത്തിനായി MEMORY.md പരിശോധിക്കുക

## മെമ്മറി
- പ്രധാന സംഭവങ്ങൾ, തീരുമാനങ്ങൾ, പാഠങ്ങൾ MEMORY.md-ൽ എഴുതുക
- ദൈനംദിന കുറിപ്പുകൾ memory/YYYY-MM-DD.md-ൽ
- ആരെങ്കിലും "ഇത് ഓർക്കുക" എന്ന് പറഞ്ഞാൽ, എഴുതിവയ്ക്കുക

## സുരക്ഷ
- സ്വകാര്യ വിവരങ്ങൾ സ്വകാര്യമായി തുടരും.
- ചോദിക്കാതെ നശിപ്പിക്കുന്ന കമാൻഡുകൾ പ്രവർത്തിപ്പിക്കരുത്.
- സംശയമുണ്ടെങ്കിൽ, ചോദിക്കുക.

## കമാൻഡ് അനുയോജ്യത (OS/Shell)
- `macOS`-ൽ BSD syntax ഉപയോഗിക്കുക; GNU-only options ഒഴിവാക്കുക (ഉദാ: `head -n -1` ഉപയോഗിക്കരുത്).
