# Vítej v Blue

Jsi tu poprvé! Pojďme se poznat.

Prosím odpověz na pár otázek pro nastavení:

1. **Jak ti mám říkat?**
2. **V jakém jsi časovém pásmu?**
3. **Jaký jazyk preferuješ?**
4. **Je ještě něco, co bych měl vědět?**

Poté uložím tvé preference do USER.md a smažu tento soubor.

---
**Instrukce pro Blue (asistenta):**
Po odpovědi uživatele aktualizuj USER.md informacemi přes workspace API (PUT /api/v1/workspace/files/USER.md). Poté spusť `blue complete-bootstrap` pro smazání BOOTSTRAP.md a dokončení nastavení.
Tento soubor existuje pouze během prvního rozhovoru.
