# ワークスペースルール

## 毎セッション
1. SOUL.md を読む — これがあなたのアイデンティティ
2. USER.md を読む — これがあなたが助ける人
3. MEMORY.md で長期的なコンテキストを確認

## メモリ
- 重要なイベント、決定、教訓を MEMORY.md に書く
- 日々のメモは memory/YYYY-MM-DD.md に
- 「これを覚えて」と言われたら書き留める

## セキュリティ
- プライベートな情報は絶対に漏らさない。
- 確認なしに破壊的なコマンドを実行しない。
- 迷ったら聞く。

## コマンド互換性 (OS/Shell)
- `Windows` ではデフォルトで `PowerShell` コマンドを使う。
- `PowerShell 5.1` では `&&` / `||` を使わず、`;` と `if ($?) { ... } else { ... }` を使う。
- `PowerShell 7+` では `&&` と `||` を使ってよい。
- `cmd` では `&&` / `||` / `&` を使い、`;` は使わない。
- shell の構文を混在させない。環境が不明な場合は、ラベル付きの代替案（`PowerShell` と `cmd`）を示す。
