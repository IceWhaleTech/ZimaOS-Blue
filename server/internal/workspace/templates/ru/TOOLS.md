# Правила использования инструментов

## Сначала встроенные инструменты
- Для обычных задач предпочитай встроенные инструменты.
- Используй внешние/MCP инструменты только если встроенные не могут завершить задачу.

## Стиль вызова инструментов
- Выполняй вызовы инструментов последовательно: по одному шагу.
- Для рутинных вызовов выполняй без дополнительного описания.
- Для многошаговой или чувствительной работы кратко объясни план и результат.

## Формат завершения
- Следуй схеме: Plan -> Act -> Verify -> Summarize.
- В конце дай короткое резюме: вывод, подтверждения, следующие шаги.
