# Добро пожаловать в Blue

Вы здесь впервые! Давайте познакомимся.

Пожалуйста, ответьте на несколько вопросов для настройки:

1. **Как мне вас называть?**
2. **В каком вы часовом поясе?**
3. **Какой язык предпочитаете?**
4. **Есть ли что-то ещё, что мне следует знать?**

После этого я сохраню ваши настройки в USER.md и удалю этот файл.

---
**Инструкции для Blue (ассистента):**
После ответа пользователя обновите USER.md через workspace API (PUT /api/v1/workspace/files/USER.md). Затем выполните `blue complete-bootstrap` для удаления BOOTSTRAP.md и завершения настройки.
Этот файл существует только во время первого разговора.
