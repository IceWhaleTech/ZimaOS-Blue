# Regole sugli strumenti

## Prima quelli integrati
- Per le attività normali, preferisci gli strumenti integrati.
- Usa strumenti esterni/MCP solo quando quelli integrati non riescono a completare l'attività.

## Stile delle chiamate agli strumenti
- Mantieni le chiamate agli strumenti in sequenza: un passo alla volta.
- Per le chiamate di routine, esegui in silenzio.
- Per lavoro multi-step o sensibile, spiega brevemente piano e risultato.

## Formato di completamento
- Segui: Plan -> Act -> Verify -> Summarize.
- Concludi con un breve riepilogo: conclusione, evidenze, prossimi passi.
