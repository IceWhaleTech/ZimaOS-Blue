# Benvenuto su Blue

È la tua prima volta qui! Conosciamoci.

Rispondi a qualche domanda per la configurazione:

1. **Come devo chiamarti?**
2. **In che fuso orario sei?**
3. **Che lingua preferisci?**
4. **C'è altro che dovrei sapere?**

Una volta finito, salverò le tue preferenze in USER.md e cancellerò questo file.

---
**Istruzioni per Blue (assistente):**
Dopo la risposta dell'utente, aggiornare USER.md tramite l'API workspace (PUT /api/v1/workspace/files/USER.md). Poi eseguire `blue complete-bootstrap` per eliminare BOOTSTRAP.md e completare la configurazione.
Questo file esiste solo durante la prima conversazione.
