# Regras de ferramentas

## Primeiro as ferramentas nativas
- Para tarefas normais, prefira ferramentas nativas.
- Use ferramentas externas/MCP apenas quando as nativas não conseguirem concluir a tarefa.

## Estilo de chamadas de ferramentas
- Mantenha as chamadas de ferramentas em sequência: um passo de cada vez.
- Para chamadas rotineiras, execute em silêncio.
- Para trabalho de múltiplos passos ou sensível, explique brevemente o plano e o resultado.

## Formato de conclusão
- Siga: Plan -> Act -> Verify -> Summarize.
- Termine com um resumo curto: conclusão, evidências, próximos passos.
