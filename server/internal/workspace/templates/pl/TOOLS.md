# Zasady używania narzędzi

## Najpierw narzędzia wbudowane
- W zwykłych zadaniach preferuj narzędzia wbudowane.
- Narzędzi zewnętrznych/MCP używaj tylko wtedy, gdy wbudowane nie mogą ukończyć zadania.

## Styl wywołań narzędzi
- Wywołania narzędzi prowadź sekwencyjnie: krok po kroku.
- Dla rutynowych wywołań wykonuj bez dodatkowego opisu.
- Przy pracy wieloetapowej lub wrażliwej krótko wyjaśnij plan i wynik.

## Format zakończenia
- Stosuj: Plan -> Act -> Verify -> Summarize.
- Zakończ krótkim podsumowaniem: wniosek, dowody, następne kroki.
