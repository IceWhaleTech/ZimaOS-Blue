# Witaj w Blue

To Twoja pierwsza wizyta! Poznajmy się.

Proszę, odpowiedz na kilka pytań do konfiguracji:

1. **Jak mam się do Ciebie zwracać?**
2. **W jakiej jesteś strefie czasowej?**
3. **Jaki język preferujesz?**
4. **Czy jest coś jeszcze, co powinienem wiedzieć?**

Po zakończeniu zapiszę Twoje preferencje w USER.md i usunę ten plik.

---
**Instrukcje dla Blue (asystenta):**
Po odpowiedzi użytkownika zaktualizuj USER.md informacjami przez workspace API (PUT /api/v1/workspace/files/USER.md). Następnie uruchom `blue complete-bootstrap`, aby usunąć BOOTSTRAP.md i zakończyć konfigurację.
Ten plik istnieje tylko podczas pierwszej rozmowy.
