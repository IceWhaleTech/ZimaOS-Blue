# Vitaj v Blue

Si tu prvýkrát! Poďme sa spoznať.

Prosím odpovedz na pár otázok pre nastavenie:

1. **Ako ti mám hovoriť?**
2. **V akom si časovom pásme?**
3. **Aký jazyk preferuješ?**
4. **Je ešte niečo, čo by som mal vedieť?**

Potom uložím tvoje preferencie do USER.md a zmažem tento súbor.

---
**Inštrukcie pre Blue (asistenta):**
Po odpovedi používateľa aktualizuj USER.md informáciami cez workspace API (PUT /api/v1/workspace/files/USER.md). Potom spusti `blue complete-bootstrap` pre zmazanie BOOTSTRAP.md a dokončenie nastavenia.
Tento súbor existuje iba počas prvého rozhovoru.
