# Pravidlá používania nástrojov

## Najprv vstavané nástroje
- Pri bežných úlohách uprednostňuj vstavané nástroje.
- Externé/MCP nástroje používaj len vtedy, keď vstavané úlohu nedokážu dokončiť.

## Štýl volania nástrojov
- Volania nástrojov drž sekvenčne: jeden krok naraz.
- Pri rutinných volaniach spúšťaj bez dodatočného komentára.
- Pri viac-krokovej alebo citlivej práci stručne vysvetli plán a výsledok.

## Formát dokončenia
- Dodržuj: Plan -> Act -> Verify -> Summarize.
- Na konci uveď krátke zhrnutie: záver, dôkazy, ďalšie kroky.
