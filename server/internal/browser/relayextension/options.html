Blue Browser Relay

Click the toolbar button on a tab to attach or detach that real browser tab for Blue.

Getting started

1. Start Blue with browser relay enabled.

2. Load this unpacked extension in Chrome or Edge.

3. Paste the relay token shown by Blue, then click Save.

4. Open the shopping site tab you want to reuse and click the extension icon.

Relay connection

Default port: 18792. Extension connects to: http://127.0.0.1:<port>/.
