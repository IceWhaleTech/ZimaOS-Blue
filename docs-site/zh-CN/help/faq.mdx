# 常见问题

## 这是正式公开文档站吗

还不是。第一版先把文档站结构落进仓库，并接入 CI 校验，再做后续公开部署。

## Wiki 在哪里

使用 [DeepWiki](https://deepwiki.com/IceWhaleTech/ZimaOS-Blue)。文档站负责精选路径，DeepWiki 负责更广的仓库知识入口。做仓库研究时，先看 DeepWiki，再去 GitHub 校验文件、Issue、PR、工作流运行状态和当前仓库状态。

## 哪个语言版本是主文

英文是首版 canonical 文档，简体中文同步首批用户向页面。

## 我应该从哪里开始

先看 [开始使用](/zh-CN/start/getting-started)，再看 [安装方式](/zh-CN/start/installation) 和 [快速开始](/zh-CN/start/quick-start)。
