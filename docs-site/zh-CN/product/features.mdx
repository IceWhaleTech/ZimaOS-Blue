# 产品能力

![Feature overview](/assets/features.png)

Blue 现在已经不只是“聊天 + 模型接入”，而是覆盖运行时配置、Provider 路由、自动化评测、扩展、语音与运维治理的一整套产品面。

## 本地优先运行时

Blue 的定位是自托管、本地优先、可审计的 AI 代理运行时。

## 轻量运行时

仓库当前 README 强调 Go 原生实现、低内存占用与跨设备部署能力。

## 多入口交互

- Web 管理界面
- 聊天与消息渠道
- 语音相关能力
- 定时任务、Webhook 与自动化入口
- 表单填充与结构化浏览器辅助能力
- 外部代理协同入口
- 聊天里统一的 `Research` 入口，可在 deep research、analyze 与 UI review 之间自动路由，同时保留不同的最终结果呈现

## 统一的 Research 工作流

Blue 现在把研究相关能力统一成一个 family，而不是三个互相独立的对外入口。

- `research` 是统一的公开入口
- `mode=auto` 可以在 `deep_research`、`analyze`、`ui_review` 之间自动选择
- 内部运行时共享一个 research-family job 模型
- 最终面向用户的结果仍然按 mode 分开呈现

继续阅读 [Research 工作流](/zh-CN/guides/research-workflows) 了解路由线索、各 mode 的输入结构和对外接口约定。
