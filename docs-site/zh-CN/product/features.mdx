# 产品能力

![Feature overview](/assets/features.png)

Blue 现在已经不只是“聊天 + 模型接入”，而是一套本地优先、可评测、可进化、可长期运行的智能体运行时。下面这版按产品承诺压成能力矩阵，方便更快看清系统边界。

| 能力 | 交付价值 |
| --- | --- |
| Harness 运行时、评测与进化框架 | 把智能体评测做成一等公民：开发、训练与线上运行共用一套 Harness，支持回归、冒烟、评分、报告、运行产物、执行轨迹、基线对比和运行时校验；同时把进化与经验沉淀也纳入同一条证据链，覆盖运行时触发的技能进化、版本修订、后续评测、上线切换、回滚，以及 `AGENTS.md` / 指令提案审批。这类提案来自执行闭环中的 Ralph 循环、自动确认和任务后反思。 |
| 多模态原生能力优先 | 把语音、OCR、PDF、浏览器能力、文档转换、结构化表单填充、多媒体处理和媒体生成放进同一条原生优先链路：能在本地和系统能力内完成的任务就不绕远路到外部模型，延迟更低、可靠性更高、成本更稳；需要时还能通过意图驱动路由进入 `t2i`、`t2v`、`i2v`、`i2i` 生成链路，并在无外部密钥时提供降级 fallback，而不只是做媒体理解。 |
| 研究三合一运行时 | 对外统一暴露一个 `research` 入口，内部可在 `deep_research`、`analyze`、`ui_review` 三种模式之间自动路由；底层保留可控搜索、多源并发、缓存去重、结果融合、策略化抓取和页面阅读能力，最终可直接交付带引用的深度研究、分析报告和结构化界面 / 体验 / 无障碍审核结果。 |
| 安全与治理能力 | 包括沙箱执行、提示注入防护、会话审计、权限控制、RBAC、WebAuthn、风险拦截与治理，以及技能的安全审计与扫描；在网页访问场景下还支持请求头、Cookies、令牌、会话复用，并默认拦截私有主机、控制重定向和限制响应体积。 |
| 知识空间 | 把记忆、研究结果和运行产物继续沉淀成 wiki 化知识页，而不只是临时召回：支持知识编译、摘要页、索引、反向链接、时效管理和归档等长期知识经营。 |
| 技能商店 / 市场 | 提供技能发现、策展、同步和本地扫描，开箱即可扩展，不必从零搭扩展生态。 |
| 生产级提供方池 | 不是简单故障回退，而是底层就有提供方池、健康检查、自动故障转移、熔断和多提供方竞速，适合长期在线和生产流量。 |
| 内置本地小模型运行时 | 内建 `Qwen3.5-0.8B + llama.cpp` 小模型运行时，支持自动下载和本地加速，可接手短问答、图片识别、工具分流、摘要、上下文压缩与文档预处理。 |
| 长期运行可靠性 | OTA、备份恢复、配置热重载和故障后恢复都是产品内建能力，适合真正长期部署。 |
