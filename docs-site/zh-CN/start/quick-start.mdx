# 快速开始

## 1. 先完成安装

从 [安装方式](/zh-CN/start/installation) 选择一种方式。

## 2. 认识产品的三个核心层

- **运行时**：Blue 是轻量级 Go 运行时
- **路由层**：模型与提供方通过配置完成选择、故障转移与回退
- **交互面**：通过聊天、语音、自动化和 Web 界面与系统交互

## 3. 打开关键页面

- [产品能力](/zh-CN/product/features)
- [文档导航](/zh-CN/start/docs-directory)
- [常见问题](/zh-CN/help/faq)
- [故障排查](/zh-CN/help/troubleshooting)

做仓库研究时，先看 [DeepWiki](https://deepwiki.com/IceWhaleTech/ZimaOS-Blue)，再去 GitHub 校验精确文件、Issue、PR 和实时状态。
