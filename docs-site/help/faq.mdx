# FAQ

## Is this the deployed public docs site

Not yet. This first release lands the docs structure in-repo so it can be previewed locally and validated in CI before public hosting is added. See [Deployment](/help/deployment) for the rollout model.

## Where is the wiki

Use [DeepWiki](https://deepwiki.com/IceWhaleTech/ZimaOS-Blue). The docs site is the curated path; DeepWiki is the broader external repository knowledge entry.

## Which language is canonical

English is the canonical docs source for this first release. Simplified Chinese mirrors the first user-facing pages.

## Does Blue only target chat

No. The repository already spans chat, voice, automation, browser-oriented integrations, security, tenancy, backup, and admin surfaces.
