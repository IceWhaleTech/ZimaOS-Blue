# Troubleshooting

## If you are unsure where to go

Open [Docs Directory](/start/docs-directory) and then branch into the most relevant guide.

## Common problem buckets

### Install confusion

- Re-check [Installation](/start/installation)
- Make sure you chose the correct path for desktop app, install script, or source build
- On Windows source builds, verify the prerequisites called out in the install page

### Product surface confusion

- Read [Overview](/product/overview) to separate runtime, routing, and surfaces
- Read [Features](/product/features) to map the UI and capabilities back to product intent

### Channel setup questions

- Read [Channels](/guides/channels)
- Verify you have the correct credentials or pairing flow for the target platform

### Provider or model routing questions

- Read [Providers and Models](/guides/providers-models)
- Check default provider, provider ordering, and fallback assumptions in your config

### Automation questions

- Read [Automation](/guides/automation)
- Confirm whether you need cron, webhook, browser, or workflow behavior

## Need repo-wide context

Use [DeepWiki](https://deepwiki.com/IceWhaleTech/ZimaOS-Blue) when the curated docs are not deep enough for the question you are debugging.

## Need publish setup guidance

Read [Deployment](/help/deployment) for the Mintlify connection and cutover checklist.
