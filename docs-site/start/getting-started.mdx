# Getting Started

Use this page if you want the shortest path from repository landing page to a working mental model.

## Who this is for

ZimaOS Blue is aimed at developers and builders who want:

- A self-hosted agent runtime instead of a hosted black box
- Control over model choice, routing, and deployment shape
- Rich interaction surfaces such as chat, voice, automation, and web UI
- A system that can scale from desktop experimentation to production setups

## Recommended first path

1. Read [Overview](/product/overview)
2. Pick an [Installation](/start/installation) path
3. Follow [Quick Start](/start/quick-start)
4. Configure [Settings and Provider Pool](/guides/settings-provider-pool)
5. Review [Identity and Access](/guides/identity-access) if you need preview bootstrap, auth providers, or user management
6. Explore [Channels](/guides/channels) and [Providers and Models](/guides/providers-models)
7. Keep [Docs Directory](/start/docs-directory) open for deeper navigation
