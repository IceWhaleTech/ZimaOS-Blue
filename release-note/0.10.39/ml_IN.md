# ZimaOS Blue v0.10.39

പ്രസിദ്ധീകരിച്ചത്: 2026-04-09

ഏകീകൃത Research പ്രവാഹങ്ങൾ, പുതിയ Knowledge, Evolution പ്രവർത്തനപ്രദേശങ്ങൾ, കൂടുതൽ ശക്തമായ സംഭാഷണ പുനഃസ്ഥാപനം, കൂടാതെ ഡോക്യുമെന്റ് എക്സ്ട്രാക്ഷനും നിർവഹണ വിശ്വാസ്യതയും മെച്ചപ്പെടുത്തിയ റിലീസാണ് ഇത്.

## പ്രധാന സവിശേഷതകൾ

- research, knowledge, evolution ജോലികൾക്കായി കൂടുതൽ ഏകീകൃതമായ പ്രവർത്തന പ്രവാഹം
- സജീവമായതോ കാത്തിരിക്കുന്നതോ ആയ സംഭാഷണങ്ങളിലേക്ക് മടങ്ങുമ്പോൾ മികച്ച പുനഃസ്ഥാപനം
- ഡോക്യുമെന്റ് എക്സ്ട്രാക്ഷനും നിയന്ത്രിത നിർവഹണത്തിനും കൂടുതൽ വിശ്വാസ്യത

## പുതിയത്

- മോഡ് അടിസ്ഥാനത്തിലുള്ള ഔട്ട്പുട്ട് നിലനിർത്തിക്കൊണ്ട് ഏകീകൃത `Research` എൻട്രി ചേർത്തു
- സമാഹരിച്ച പേജുകൾ, lint നില, ask-and-archive ജോലികൾ എന്നിവയ്ക്കായി `Knowledge` പ്രവർത്തനപ്രദേശം ചേർത്തു
- അവലോകനത്തിനും നിർണയത്തിനുമായി `Evolution` കൺസോളും പ്രാദേശിക `blue audit` ഉപകരണവും ചേർത്തു

## മെച്ചപ്പെടുത്തിയത്

- വീണ്ടും തുറക്കുന്ന ചാറ്റുകൾക്ക് കൂടുതൽ സജീവാവസ്ഥയും കാത്തിരിക്കുന്ന അനുമതികളും പുനഃസ്ഥാപിക്കാനാകുന്ന വിധത്തിൽ സംഭാഷണ bootstrap മെച്ചപ്പെടുത്തി
- കൂടുതൽ ആവർത്തിക്കാനാകുന്ന മൂല്യനിർണയ പ്രവർത്തനങ്ങൾക്ക് Harness dataset പ്രവാഹങ്ങൾ മെച്ചപ്പെടുത്തി
- context compression, failover കൈകാര്യം ചെയ്യൽ, പ്രാദേശികവൽക്കരണ സ്ഥിരത എന്നിവ മെച്ചപ്പെടുത്തി

## പരിഹരിച്ചത്

- provider catalog പരിശോധനയിലെ refresh loop പ്രശ്നങ്ങൾ പരിഹരിച്ചു
- artifact recovery കൈകാര്യം ചെയ്ത് ആവർത്തിക്കുന്ന read-loop സാഹചര്യങ്ങൾ പരിഹരിച്ചു
- PDF ടെക്സ്റ്റ് എക്സ്ട്രാക്ഷനിലെ തെറ്റായ അക്ഷരങ്ങൾ ശരിയാക്കുന്ന പ്രശ്നം പരിഹരിച്ചു

## സുരക്ഷ

- `blue exec` ഉം തലമേറ്റ sandbox routing ഉം ഉപയോഗിച്ച് കമാൻഡ് നിർവഹണം കൂടുതൽ ശക്തമാക്കി
