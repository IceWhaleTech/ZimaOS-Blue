# ZimaOS Blue v0.10.39

Publicado: 2026-04-09

Flujos de Research unificados, nuevos espacios de Knowledge y Evolution, recuperación de conversaciones más sólida y mejor fiabilidad en la extracción de documentos y la ejecución.

## Novedades destacadas

- Un flujo más unificado para tareas de research, knowledge y evolution
- Mejor recuperación al volver a conversaciones activas o en espera
- Mayor fiabilidad para la extracción de documentos y la ejecución controlada

## Nuevo

- Se añadió una entrada unificada de `Research` manteniendo salidas específicas por modo
- Se añadió un espacio de trabajo `Knowledge` para páginas compiladas, estado de lint y tareas ask-and-archive
- Se añadió una consola `Evolution` y herramientas locales de `blue audit` para revisión y diagnóstico

## Mejorado

- Se mejoró el bootstrap de conversaciones para que los chats reabiertos restauren más estado activo y aprobaciones pendientes
- Se mejoraron los flujos de datasets de Harness para ejecuciones de evaluación más repetibles
- Se mejoraron la compresión de contexto, el manejo de failover y la consistencia de localización

## Corregido

- Se corrigieron los bucles de actualización en la verificación del catálogo de proveedores
- Se corrigieron los escenarios de bucles de lectura repetidos con recuperación de artefactos
- Se corrigió la reparación de caracteres malformados durante la extracción de texto PDF

## Seguridad

- Se reforzó la ejecución de comandos con `blue exec` y enrutamiento de sandbox por niveles
