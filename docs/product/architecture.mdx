## Hot path: chat request

```text
Client -> Auth Gate -> Prompt Guard -> Context Pruner
  -> Provider Pool -> Cache Checks -> Upstream Model
  -> Response -> Cache Store -> Metrics -> Client
```

## Hot path: channel message

```text
Chat Platform -> Channel Manager -> AutoReply
  -> Chat Handler -> LLM -> Humanizer -> Channel -> User
```

## Hot path: voice pipeline

```text
Audio Stream -> STT -> LLM Processing -> TTS -> Audio Stream
```

## Hot path: tracked evaluation

```text
Operator -> Harness UI/API -> Dataset / Eval Spec / Run Group
  -> Agent or Workflow Execution -> Scorecard / Artifact / Report
  -> Comparison / Baseline Review -> Evolution Decision
```

## Hot path: extension install and review

```text
Operator -> Extensions UI -> Skill Source / Store Search
  -> Security Metadata / Contract Review -> Install
  -> Skill or Tool becomes available to runtime surfaces
```

## What matters most

- Gateway and provider routing are central control points
- Messaging, voice, automation, and web UI are interaction surfaces over the same runtime core
- Harness and Evolution are part of the runtime architecture, not side diagnostics
- Extension safety metadata is now part of the operator experience, not an afterthought
- Security, audit, and sandboxing are first-class design constraints, not bolt-ons
