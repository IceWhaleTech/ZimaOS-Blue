## What is ZimaOS Blue

ZimaOS Blue is a local-first agent runtime and toolkit for developers who want to build, ship, and operate private AI agents without giving up control of data, deployment, or model choice.

It is designed around a few core ideas already reflected in this repository:

- Local-first operation across desktop, server, NAS, Raspberry Pi, and edge devices
- Auditable execution with sandboxing, session tracing, and permission boundaries
- Multi-channel messaging and voice surfaces for always-available assistants
- Open provider routing so teams can mix cloud APIs and local models

## Product snapshot

![Feature overview](/assets/features.png)

- Fast Go-based runtime with a low memory footprint
- 20+ messaging integrations and voice-oriented experiences
- Provider pool, custom providers, external agents, failover, and model family routing
- Harness, eval datasets, skill evolution, and reusable tracked runs
- Skill store, tool catalog, extension security badges, and curated install flows
- Security controls including sandbox execution, prompt defenses, auditing, billing, tenancy, RBAC, and WebAuthn
