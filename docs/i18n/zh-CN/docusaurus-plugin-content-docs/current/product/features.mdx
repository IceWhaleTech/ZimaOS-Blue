# 产品能力

![Feature overview](/features.png)

Blue 现在已经不只是“聊天 + 模型接入”，而是一套本地优先、可评测、可进化、可长期运行的智能体运行时。
其中最需要单独强调的，是网页检索与浏览器运行时。

| 能力 | 交付价值 |
| --- | --- |
| 高可用网页检索与浏览器运行时 | 这是 Blue 最该被单独强调的能力之一。它不是简单“搜一下网页”，而是统一了搜索、读取、提取、爬取 4 种网页接入方式，具备 HTTP、代理提取、浏览器会话 3 层高可用回退；遇到登录墙、限流、验证页等反爬场景时，可做挑战识别、Cookie / 会话复用、stealth 和浏览器接管；底层还能在 `lightpanda`、托管 Chromium、本地 / relay Chrome 3 类浏览器引擎路径之间路由。 |
| 研究三合一运行时 | 对外统一一个 `research` 入口，内部按场景路由到 `deep_research`、`analyze`、`ui_review`；同一套发现与证据链可以直接产出带引用研究、分析报告，以及结构化的 UI / UX / 无障碍审查结果。 |
| 评测运行时与进化框架 | 把评测做成运行时底座。开发、训练、线上共用一套评测体系，可做回归、冒烟、评分、基线对比、报告和运行校验；同一条证据链还能继续覆盖技能进化、后续评测、上线切换、回滚，以及 `AGENTS.md` / 指令提案审核。 |
| 多模态原生能力优先 | 语音、OCR、PDF、浏览器任务、文档转换、结构化表单填充、多媒体处理和媒体生成优先走本地与系统能力，只有真正需要时才路由到外部模型。 |
| 安全与治理能力 | 包括沙箱执行、提示注入防护、会话审计、权限控制、RBAC、WebAuthn、运行时防护，以及技能安全审计与扫描。 |
| 知识空间 | 把记忆、研究结果和运行产物继续沉淀成 wiki 化知识面，支持摘要页、索引、反向链接、时效管理和归档。 |
| 技能商店 / 市场 | 提供内置技能发现、策展、同步和本地扫描，扩展能力从第一天就可用。 |
| 生产级提供方池 | 底层不是简单 fallback，而是完整提供方池，包含健康检查、自动故障转移、熔断和多提供方竞速。 |
| 内置本地小模型运行时 | 内建 `Qwen3.5-0.8B + llama.cpp`，可在本地接手短问答、图片识别、工具分流、摘要、上下文压缩和文档预处理。 |
| 长期运行可靠性 | OTA、备份恢复、配置热重载和故障后恢复都是内建能力，适合长期部署。 |

## 按能力组来理解

如果把上面的矩阵重新收拢成更大的几类，会更容易理解：

- **面向构建者的加速层**：研究、浏览器运行时、多模态工具、知识空间和扩展能力，减少了大量胶水代码工作。
- **面向运营者的控制层**：提供方池、安全、治理、审计、计费和长期运行可靠性，让系统可以从 demo 走向长期运行。
- **面向持续改进的评测层**：评测与进化让回归、对比、审核和版本切换进入日常工作流，而不是额外平台。
- **面向生态接入的边界层**：渠道、提供方、Coding IDE 和外部 agent 都能围绕同一套运行时核心接入。
