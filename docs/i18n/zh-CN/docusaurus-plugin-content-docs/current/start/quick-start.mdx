# 快速开始

这一页默认你已经完成安装，并且已经按 [首次运行](/start/first-run) 跑通了一次本地启动与首条响应验证。

## 1. 先完成安装

从 [安装方式](/start/installation) 选择一种方式。

## 2. 先完成首跑检查

按 [首次运行](/start/first-run) 完成：

- 本地启动 Blue
- 判断当前是 preview mode 还是 normal mode
- 接入一个可用 provider
- 验证第一条聊天响应成功返回

## 3. 认识产品的三个核心层

- **运行时**：Blue 是轻量级 Go 运行时
- **路由层**：模型与提供方通过配置完成选择、故障转移与回退
- **交互面**：通过聊天、语音、自动化和 Web 界面与系统交互
