# 开始使用

如果你刚从仓库首页进入，这一页是最短的理解路径。

![当前产品大致会看到什么](/demo%20quickv4.gif)

## Blue 适合谁

- 想要自托管 AI 代理而不是托管黑盒的人
- 需要自己控制模型、部署和集成方式的开发者
- 希望同时拥有聊天、语音、自动化和 Web 管理界面的团队

## 建议第一步

1. 先看 [安装方式](/start/installation)
2. 再看 [首次运行](/start/first-run)
3. 然后看 [快速开始](/start/quick-start)
4. 配置 [设置与提供方池](/guides/settings-provider-pool)
5. 如果要处理登录、预览模式、用户或认证提供方，再看 [身份与访问](/guides/identity-access)
6. 需要地图时打开 [文档导航](/start/docs-directory)
7. 需要更深仓库上下文时先看 [DeepWiki](https://deepwiki.com/IceWhaleTech/ZimaOS-Blue)，再去 GitHub 校验精确当前状态

## 一个理想的第一小时应该得到什么

如果第一轮阅读和启动顺利，你应该已经能回答：

- Blue 的主要产品面和运维面分别在哪里

- 第一次本地启动和第一条响应该如何验证
- 下一步该去看 Provider、身份、安全、自动化还是评测文档
