## ZimaOS Blue 是什么

ZimaOS Blue 是一套面向自托管场景的本地优先 AI 代理运行时与工具箱，目标不是把你锁进某个托管模型，而是在自己的硬件、网络与运维边界里，把聊天、语音、自动化、检索、评测与治理组合起来。

它当前特别适合这些场景：

- 想自己掌控数据、模型与部署方式的开发者
- 希望把聊天、语音、渠道接入和自动化放进同一套运行时的团队
- 需要评测、审计、安全治理，而不是只做 demo 的操作者

## 能力快照

![Feature overview](/features.png)

- Go 运行时，强调轻量、本地优先与长期运行
- 提供方池、模型路由、外部 agent 和多渠道接入
- 聊天、语音、网页检索、自动化与表单填充等交互面
- Harness、评测、进化与可追踪运行
- 沙箱、安全、审计、计费、租户、身份与权限治理
