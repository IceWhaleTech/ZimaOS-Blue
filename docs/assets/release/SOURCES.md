# ZimaOS release banners

The English and Chinese banners reuse the layout from FiLens'
[`generate-zimaos-banners.py`](https://github.com/orca-zhang/filens/blob/v0.6.5/scripts/generate-zimaos-banners.py),
with integration copy changed to describe Blue's local AI agents.
The official ZimaOS logo is unchanged and comes from
[`IceWhaleTech/ZimaOS`](https://github.com/IceWhaleTech/ZimaOS/blob/main/assets/20241126-153324.png).
ZimaOS branding belongs to IceWhale. Each PNG is rendered with librsvg at
1280 × 256 and displayed at 640 × 128.

Release links use `utm_source=github`, `utm_medium=referral`,
`utm_campaign=blue_zimaos`, and language-specific `release_banner_en` /
`release_banner_zh` content tags.
