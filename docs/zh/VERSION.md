# 版本计划

[English Version](../VERSION.md)

本文档描述 ZimaOS-Echo 项目的版本规划和发布策略。

## 版本号规范

项目采用 [语义化版本 2.0.0](https://semver.org/lang/zh-CN/)：

```
主版本号.次版本号.修订号 (MAJOR.MINOR.PATCH)
```

- **主版本号**: 不兼容的 API 变更
- **次版本号**: 向下兼容的功能新增
- **修订号**: 向下兼容的问题修复

## 发布周期

| 版本类型 | 发布频率 | 说明 |
|---------|---------|------|
| 主版本 | 按需 | 重大架构变更或不兼容更新 |
| 次版本 | 按需 | 新功能发布 |
| 修订版 | 按需 | Bug 修复和小改进 |

## 分支策略

| 分支 | 用途 |
|------|------|
| `main` | 稳定版本，生产就绪 |
| `develop` | 开发分支，集成最新功能 |
| `feature/*` | 功能开发分支 |
| `hotfix/*` | 紧急修复分支 |
| `release/*` | 发布准备分支 |

## 发布流程

1. 功能开发在 `feature/*` 分支进行
2. 完成后合并到 `develop` 分支
3. 准备发布时创建 `release/*` 分支
4. 测试通过后合并到 `main` 并打 tag
5. 更新 CHANGELOG.md

## 预发布版本

- **Alpha** (`x.x.x-alpha.n`): 早期开发，不稳定
- **Beta** (`x.x.x-beta.n`): 功能完整，测试阶段
- **RC** (`x.x.x-rc.n`): 发布候选，最终测试

## 兼容性策略

- **v0.x.x**: 次版本之间 API 可能变更
- **v0.5.0+**: API 稳定，修订版内保证向后兼容
