# ZimaOS-Echo 架构文档

[English Version](../../../../plan/DEV/architecture.md)

## 概述

ZimaOS-Echo 是一个轻量级、自托管的 AI 助手，专为 NAS 环境设计。它提供了一个对话界面，可以与各种 LLM 提供商交互，同时保持对数据的隐私和控制。

## 核心组件

### 1. API 网关层

API 网关基于 [Echo](https://echo.labstack.com/) 构建，这是一个高性能的 Go Web 框架。

**主要特性：**
- RESTful API 端点
- WebSocket 支持流式响应
- 中间件链处理横切关注点
- 请求/响应日志
- Prometheus 指标集成

### 2. 认证与授权

#### JWT 认证
- 可配置过期时间的访问令牌
- 刷新令牌机制
- 令牌黑名单用于撤销
- 安全的令牌存储

#### API Key 管理
- 带作用域的 API 密钥用于程序化访问
- SHA-256 哈希存储
- 使用跟踪和速率限制

#### RBAC（基于角色的访问控制）
- 预定义角色：admin、user、readonly
- 通配符权限匹配
- 角色继承支持

### 3. 插件系统

插件系统支持多种插件类型：

#### 原生 Go 插件
- 编译时集成
- 完全访问内部 API
- 最佳性能

#### JavaScript 插件（clawdbot 兼容）
- 通过 goja 运行时加载
- 支持 clawdbot manifest 格式
- 沙箱化执行

**插件生命周期：**
```
加载 → 初始化 → 启动 → 运行中 → 停止 → 销毁
```

### 4. Skill Hub

Skills 是独立的功能单元：

**内置 Skills：**
- Calculator - 算术运算
- DateTime - 日期/时间工具
- SystemInfo - 系统信息
- Weather - 天气数据（需要 API）
- Search - 文本搜索工具

**Skill 接口：**
```go
type Skill interface {
    Manifest() *Manifest
    Execute(ctx context.Context, input map[string]any) (*Result, error)
    Validate(input map[string]any) error
}
```

### 5. 任务调度器

基于优先级的任务调度，具有：
- 并发执行限制
- 任务依赖
- 超时处理
- 指数退避重试
- 任务取消

### 6. LLM 提供商抽象

多个 LLM 提供商的统一接口：

| 提供商    | 流式传输 | 函数调用 |
|----------|---------|---------|
| OpenAI   | ✅      | ✅      |
| Anthropic| ✅      | ✅      |
| Ollama   | ✅      | ⚠️ 有限 |

### 7. 可观测性

#### 指标（Prometheus）
- 运行时指标（goroutines、内存、GC）
- HTTP 请求指标
- LLM 提供商指标
- 自定义业务指标

#### 性能分析（pprof）
- CPU 分析
- 内存分析
- Goroutine 分析
- 阻塞/互斥锁分析

### 8. 弹性

- 外部调用的熔断器
- 每客户端速率限制
- 优雅降级
- 热配置重载

## 数据流

### 聊天请求流程

```
1. 客户端发送消息
         │
         ▼
2. 认证中间件验证令牌
         │
         ▼
3. 速率限制器检查配额
         │
         ▼
4. 聊天服务接收请求
         │
         ▼
5. 上下文管理器加载对话历史
         │
         ▼
6. LLM 提供商发送请求到 AI
         │
         ▼
7. 响应流式返回客户端
         │
         ▼
8. 对话保存到存储
```

### 插件执行流程

```
1. 从目录加载插件
         │
         ▼
2. 验证 Manifest
         │
         ▼
3. 在注册表中注册插件
         │
         ▼
4. 调用 Initialize 并传入 API
         │
         ▼
5. 调用 Start 开始运行
         │
         ▼
6. 工具/命令可供系统使用
```

- 环境变量替换
- 无需重启的热重载
- 应用前验证
- 无效配置回滚

详见 [配置指南](./configuration.md)。

## 安全考虑

1. **认证**：所有 API 端点都需要认证
2. **授权**：RBAC 强制最小权限访问
3. **数据隐私**：所有数据本地存储，无外部遥测
4. **API 密钥**：哈希存储，作用域权限
5. **插件隔离**：沙箱化 JavaScript 执行

## 性能

- **并发请求**：可配置的工作池
- **内存**：大响应的高效流式传输
- **启动时间**：典型 < 2 秒
- **响应延迟**：主要由 LLM 提供商延迟决定

## 部署选项

1. **独立二进制**：单个可执行文件，无依赖
2. **Docker 容器**：提供官方 Docker 镜像
3. **Systemd 服务**：Linux 服务集成
4. **ZimaOS 应用**：原生 ZimaOS 应用

详见 [安装指南](./installation.md)。
