# v0.1.0 Implementation Checklist

[中文版本](./zh/v0.1.0-checklist.md)

This checklist tracks the implementation progress of v0.1.0 (Go Runtime Core + Vue 3 Frontend).

## Goal
Stable and long-running Go runtime core with Vue 3 frontend.

## Acceptance Criteria
- [ ] Can run on NAS for **24h without restart**
- [ ] Idle CPU ≈ 0%
- [ ] Resident memory < 50-80MB

## How to Run

### Backend
```bash
cd server
make deps    # Download dependencies
make test    # Run tests
make build   # Build binary
make run     # Build and run
```

### Frontend
```bash
cd web
npm install      # Install dependencies
npm run test:run # Run tests
npm run dev      # Start dev server
npm run build    # Build for production
```

### Documentation Site
```bash
cd docs-site
npm install      # Install dependencies
npm run dev      # Start dev server
npm run build    # Build static site
```
