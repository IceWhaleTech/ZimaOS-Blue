# 扩展中心

Blue 的扩展页已经从简单插件列表演进成统一的能力管理入口。

## 当前三条主线

扩展页现在分成三个主标签：

- `Skills`：当前运行时已有或已安装的技能
- `Skill Store`：远程技能发现、搜索与安装
- `Tools`：与技能并列的可复用工具能力

## 本地技能

本地技能页关注当前已经落地到运行时的能力，包括：

- 技能名称与版本
- 描述、分类、标签
- builtin / installed 区分
- 新旧 contract 元数据

## 远程技能商店

当前 skill store 不只是“搜一下然后安装”，还包含：

- 多来源技能源
- 搜索、过滤、分类浏览
- curated ranking 与趋势信号
- 新来源接入前的 import preview
- 远程技能与本地技能区分

## 安全与安装元数据

这是这次新增能力里很值得写清楚的一块。当前 skill 模型已经能暴露：

- security badge 与 risk level
- install type
- artifact kind
- vulnerability status
- prompt injection、shell injection、data exfiltration 风险信号

因此扩展页既是目录，也是安装前审查界面。

## 安装方式

当前界面支持：

- 通过 URL 安装技能
- 通过文件上传安装技能

安装成功后还可以查看返回的 contract 结果，而不是只看到一个成功提示。

## 推荐阅读顺序

1. 先看本地已有技能
2. 再去 skill store 搜缺的能力
3. 安装前确认来源、契约和安全元数据
4. 如果能力很关键，再去 Harness 做可追踪评测

## 可选的 Parallel 网页搜索

[Parallel Search MCP](https://docs.parallel.ai/integrations/mcp/search-mcp) 提供包含相关摘录和来源链接的网页搜索。匿名搜索使用 Fast 模式，无需注册账户或 API 密钥。在 `config.yaml` 中配置后重启 Blue：

```yaml
tool_calling:
  web_search:
    provider: parallel
    providers: [parallel]
```

现有的网页查询和研究搜索流程会使用此提供商，打开搜索结果时仍使用 Blue 现有的页面读取工具。在主动更改配置之前，默认提供商列表仍为 `duckduckgo,bing`。显式选择单个提供商时会直接报告失败；如需备用提供商，请配置提供商列表。

如需更高的服务限额，可在 `tool_calling.web_search.provider_settings.parallel.api_key` 中填写 Parallel API 密钥。仅发送 Parallel 专用密钥，不会转发通用搜索密钥或环境变量中的密钥。`provider_settings.parallel.base_url` 可覆盖完整的 MCP 地址，默认地址为 `https://search.parallel.ai/mcp`。设置 `provider_settings.parallel.enabled: false` 可禁用该提供商，包括单次调用中的显式选择。现有工具权限仍然生效。

匿名服务有使用限额。Parallel 不支持 Blue 的 `region` 或 `safe_search` 开关；需要这些过滤条件时，请选择其他提供商。
