# 故障排查

## 不知道先看哪里

先打开 [文档导航](/zh-CN/start/docs-directory)。

## 常见问题类型

### 安装不确定

- 回到 [安装方式](/zh-CN/start/installation)
- Windows 源码构建时重点确认依赖是否齐全

### 能力边界不清楚

- 阅读 [产品能力](/zh-CN/product/features)
- 打开 [文档导航](/zh-CN/start/docs-directory)

### Provider 或模型路由不符合预期

- 先看 [设置与 Provider Pool](/zh-CN/guides/settings-provider-pool)
- 再看 [Providers 与 Models](/zh-CN/guides/providers-models)

### 登录、预览模式、认证提供方或用户管理问题

- 阅读 [身份与访问](/zh-CN/guides/identity-access)
- 先判断问题属于 preview mode、外部登录、个人资料还是管理员用户管理

### 自动化、Harness 或技能优化结果不稳定

- 阅读 [自动化](/zh-CN/guides/automation)
- 阅读 [Harness 与 Evolution](/zh-CN/guides/harness-evolution)

### 安全、审计、计费或租户问题

- 阅读 [管理与运维](/zh-CN/guides/admin-operations)

### 需要更深仓库上下文

- 使用 [DeepWiki](https://deepwiki.com/IceWhaleTech/ZimaOS-Blue)

### 发布或站点地址问题

- 阅读 [部署](/zh-CN/help/deployment)
