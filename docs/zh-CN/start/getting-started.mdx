# 开始使用

如果你刚从仓库首页进入，这一页是最短的理解路径。

## Blue 适合谁

- 想要自托管 AI 代理而不是托管黑盒的人
- 需要自己控制模型、部署和集成方式的开发者
- 希望同时拥有聊天、语音、自动化和 Web 管理界面的团队

## 建议第一步

1. 先看 [安装方式](/zh-CN/start/installation)
2. 再看 [首次运行](/zh-CN/start/first-run)
3. 然后看 [快速开始](/zh-CN/start/quick-start)
4. 配置 [设置与 Provider Pool](/zh-CN/guides/settings-provider-pool)
5. 如果要处理登录、预览模式、用户或认证提供方，再看 [身份与访问](/zh-CN/guides/identity-access)
6. 需要地图时打开 [文档导航](/zh-CN/start/docs-directory)
7. 需要更深仓库上下文时先看 [DeepWiki](https://deepwiki.com/IceWhaleTech/ZimaOS-Blue)，再去 GitHub 校验精确当前状态
