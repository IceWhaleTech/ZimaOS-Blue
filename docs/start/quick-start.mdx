# Quick Start

This page is intentionally short. It assumes Blue is already installed and that you have completed the practical startup checks in [First Run](/start/first-run).

## 1. Pick an install path

Choose one option from [Installation](/start/installation).

## 2. Complete the first live setup

Use [First Run](/start/first-run) to:

- Launch Blue locally
- Understand preview mode versus normal mode
- Connect one working provider
- Verify that the first chat response succeeds

## 3. Start with the built-in product surfaces

The repository already shows the main areas Blue is organized around:

- Chat and voice interaction surfaces
- Channel integrations
- Automation surfaces such as cron and webhooks
- Security, tenancy, backup, and audit operations
- Settings for providers, models, and runtime behavior

## 4. Learn the three core ideas

- **Runtime**: Blue is a Go-based agent runtime meant to stay lightweight and deployable
- **Routing**: providers and models are selected through configurable routing and failover
- **Surfaces**: users interact through app UI, channels, voice, and automation entry points
