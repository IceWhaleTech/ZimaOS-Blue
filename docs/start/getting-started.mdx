# Getting Started

Use this page if you want the shortest path from repository landing page to a working mental model.

![What the current product looks like in practice](/demo%20quickv4.gif)

## Who this is for

ZimaOS Blue is aimed at developers and builders who want:

- A self-hosted agent runtime instead of a hosted black box
- Control over model choice, routing, and deployment shape
- Rich interaction surfaces such as chat, voice, automation, and web UI
- A system that can scale from desktop experimentation to production setups

## What a successful first hour looks like

By the end of an effective first pass, you should be able to say:

- I understand the product shape and where the main operator surfaces live
- I know which install path fits my environment
- I have seen Blue boot locally and return a first working response
- I know where provider, auth, automation, and evaluation docs live for the next step
