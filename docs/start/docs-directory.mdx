## When to use DeepWiki

Use [DeepWiki](https://deepwiki.com/IceWhaleTech/ZimaOS-Blue) when you want repository-oriented context beyond the curated docs, such as cross-file discovery or codebase-wide knowledge summaries. For repository research, start there before opening GitHub pages, then use GitHub for primary-source verification and live repository state.
