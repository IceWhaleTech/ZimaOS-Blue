# System Info

Returns comprehensive system information including OS, hardware, network, and GPU details.

## Usage

- "Show system info"
- "How much memory is available?"
- "What CPU is this machine running?"
- "Show disk usage"

## Parameters

- `type`: Type of info to retrieve — all, os, memory, cpu, disk, network, gpu, runtime (default: all)
