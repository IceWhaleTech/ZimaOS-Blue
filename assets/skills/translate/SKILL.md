# Translate

Translate text between languages.

## Usage

- "Translate 'hello world' to Chinese"
- "把这段话翻译成英文"
- "Translate 'bonjour' from French to Japanese"

## Parameters

- `text`: Text to translate (required)
- `from`: Source language (auto-detected if omitted)
- `to`: Target language (required)

## Supported Languages

en, zh, ja, ko, fr, de, es, pt, ru, ar, hi, it, nl, pl, sv, th, vi, id, tr, and more.
