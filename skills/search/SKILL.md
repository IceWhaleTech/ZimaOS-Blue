# Search

Search through text content using contains, regex, or fuzzy matching.

## Usage

- "Search for 'error' in the logs"
- "Find lines matching 'TODO|FIXME' in the codebase"

## Parameters

- `query`: Search pattern (required)
- `content`: Text to search in (required)
- `mode`: contains, regex, fuzzy (default: contains)
- `case_sensitive`: true/false (default: false)
