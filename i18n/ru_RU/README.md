## Введение

Вдохновленные Clawdbot, мы считаем, что будущее персональных компьютеров будет определяться разнообразными локальными агентами искусственного интеллекта, работающими на периферии.

ZimaOS Blue — это наш ответ — среда выполнения агента и набор инструментов с полностью открытым исходным кодом, проверяемая, не зависящая от поставщика и готовая к использованию, которая позволяет вам без проблем поставлять частные, автономные агенты.

Blue, созданный для смелых разработчиков, которые хотят создавать собственные агенты или создавать их вручную, создан для обеспечения высокой производительности: он написан на Go и занимает всего 19 МБ памяти. Он работает на любом x86, ![](https://raw.githubusercontent.com/drag-and-publish/operating-system-logos/master/src/16x16/RAS.png)Raspberry Pi, ![](https://raw.githubusercontent.com/drag-and-publish/operating-system-logos/master/src/16x16/WIN.png)Windows, ![](https://raw.githubusercontent.com/drag-and-publish/operating-system-logos/master/src/16x16/MAC.png)macOS — где бы вы ни подключили питание.

## Почему Blue

  <img src="../../docs/assets/design_principle.png" alt="Design Principle" />

### Pure Go, любое устройство

100% Go, статический двоичный файл. Выполняет кросс-компиляцию до 5 целевых объектов прямо из коробки (![linux](https://raw.githubusercontent.com/drag-and-publish/operating-system-logos/master/src/16x16/LIN.png) `linux/amd64`, `linux/arm64`, ![macOS](https://raw.githubusercontent.com/drag-and-publish/operating-system-logos/master/src/16x16/MAC.png) `darwin/amd64`, `darwin/arm64`, ![windows](https://raw.githubusercontent.com/drag-and-publish/operating-system-logos/master/src/16x16/WIN.png) `windows/amd64`). Ни среда выполнения Node, ни Python, ни контейнеры не требуются. Поместите его на NAS, ![](https://raw.githubusercontent.com/drag-and-publish/operating-system-logos/master/src/16x16/RAS.png)Raspberry Pi, старый маршрутизатор x86 или ![](https://raw.githubusercontent.com/drag-and-publish/operating-system-logos/master/src/16x16/MAC.png)Mac — он просто заработает. Затем добавьте свой собственный пользовательский интерфейс, логику и навыки агента — одна база кода, каждая платформа.

### Готов к работе, готов к работе

Всем нужны простые, надежные и масштабируемые инструменты, когда они вам нужны. Инструменты, которые просто работают, поэтому вы можете сосредоточиться на том, что вы на самом деле создаете.

Это не новая философия. Это тот же самый, на котором построен <a href="https://www.zimaspace.com/zimaos?utm_source=blue"><img src="https://raw.githubusercontent.com/IceWhaleTech/ZimaOS/main/assets/20241126-153324.png" alt="ZimaOS" height="18" /></a> ZimaOS: простой, надежный и созданный, чтобы не мешать вам. Blue — это философия, распространенная на стек агентов.

### Создан для вашей жизни, создан для того, чтобы оставаться локальным

От глубоких исследований, которые предоставляют полный отчет HTML, до OCR, PDF, автоматизации браузера и преобразования документов, Blue справляется со сложными реальными рабочими процессами, не отправляя ваши данные в облако. Голосовое пробуждение, STT/TTS, Talk Mode и поддержка локального вывода делают повседневное взаимодействие мгновенным, конфиденциальным и всегда доступным.

## Быстрый старт

### Вариант 1. Загрузите настольное приложение

Получите родное приложение — без зависимостей и компиляции. Встроенная пробная конфигурация с регистрацией за считанные секунды — начните общаться мгновенно через удаленное соединение, настройка бота не требуется. Настоящий нестандартный опыт.

- ![](https://raw.githubusercontent.com/drag-and-publish/operating-system-logos/master/src/16x16/MAC.png)**macOS**: [Загрузить DMG](https://github.com/IceWhaleTech/ZimaOS-Blue/releases/latest)
- ![](https://raw.githubusercontent.com/drag-and-publish/operating-system-logos/master/src/16x16/WIN.png)**Windows**: [Загрузить установщик](https://github.com/IceWhaleTech/ZimaOS-Blue/releases/latest)

### Вариант 2: Установить скрипт

![](https://raw.githubusercontent.com/drag-and-publish/operating-system-logos/master/src/16x16/MAC.png)macOS / ![](https://raw.githubusercontent.com/drag-and-publish/operating-system-logos/master/src/16x16/LIN.png)linux
```bash
curl -fsSL https://ota.zimaos.com/blue | sh
```

**![](https://raw.githubusercontent.com/drag-and-publish/operating-system-logos/master/src/16x16/WIN.png)Windows (PowerShell)**
```powershell
irm https://ota.zimaos.com/blue/windows | iex
```

### Вариант 3: сборка из исходного кода

```bash
git clone https://github.com/IceWhaleTech/ZimaOS-Blue.git
cd ZimaOS-Blue
git submodule update --init --recursive
```

![](https://raw.githubusercontent.com/drag-and-publish/operating-system-logos/master/src/16x16/MAC.png)macOS / ![](https://raw.githubusercontent.com/drag-and-publish/operating-system-logos/master/src/16x16/LIN.png)linux
```bash
sh build.sh
```

**![](https://raw.githubusercontent.com/drag-and-publish/operating-system-logos/master/src/16x16/WIN.png)Windows (PowerShell)**
```powershell
.\build.bat
```

> **Примечание.** Для сборок Windows требуется:
> - [MinGW-w64](https://www.mingw-w64.org/) (gcc) и [CMake](https://cmake.org/) для собственных зависимостей C (espeak-ng, quiet.cpp, opus, kokoro, onnx)
> - [Windows SDK](https://developer.microsoft.com/en-us/windows/downloads/windows-sdk/) для системных библиотек (winmm и т.п.)
>
> Убедитесь, что `gcc`, `cmake` находятся в вашем `PATH`.

## Как построить

<p align="center">
  <img src="../../docs/assets/handcraft.png" alt="handcraft" />
</p>

> ⚠️ [!IMPORTANT]
>
> Если вы планируете продолжать настройку или кодирование Vibe поверх Blue, не рассматривайте несколько симпатичных чатов как свидетельство релиза. Любое изменение, которое влияет на маршрутизацию, поведение выполнения, поверхность инструмента, контроль бюджета, выбор модели или структуру выполнения, должно быть проверено с помощью Blue Harness, а не с помощью специальных выборочных проверок.
>
> Blue здесь следует следовать одному простому правилу: сначала данные, сначала ворота, потом разрезание. На практике это означает обновление соответствующего набора данных / спецификации Harness перед принятием решения об изменении, а затем сохранение одного стабильного `candidate_id` на протяжении всей попытки, чтобы отчеты о выборе, выполнении, бюджете и готовности описывали одного и того же кандидата, а не четыре несвязанных запуска.

### Рекомендуемый Harness Рабочий процесс

1. Запустите `blue harness selector verify`
2. Запустите `blue harness execution verify`
3. Повторно используйте селекторный прогон для `blue harness budget gate`.
4. Завершите с помощью `blue harness cutover-readiness`.

Для локальной итерации, ночной проверки или сбора данных CI выберите `python3 scripts/cutover_candidate_pipeline.py`. Он запускает полный селектор -> выполнение -> бюджет -> последовательность готовности под одним общим кандидатом, что упрощает сравнение, анализ и вырезание результатов.

### Дополнительные ограждения

| Площадь | Что посмотреть |
|------|----------------|
| Базовая стабильность | Сохраняйте базовый уровень, версию набора данных и `candidate_id` стабильными, иначе сравнение будет смещаться, и результат не будет заслуживающим доверия. |
| Реальный результат сборки | Пересоберите затронутый двоичный файл или пакет внешнего интерфейса перед запуском Harness, иначе вместо текущего изменения вы можете проверить устаревшее поведение. |
| Регистрация маршрута | Если интерфейс и серверная часть изменяются одновременно, убедитесь, что все новые внутренние маршруты действительно зарегистрированы, прежде чем оценивать функцию по поведению пользовательского интерфейса, поскольку отсутствие регистрации часто выглядит как логическая ошибка, но на самом деле это `404`. |
| Освободить решение | Проход настройки готов только тогда, когда Harness не показывает значимой регрессии, а готовность к переключению подтверждает, что кандидат действительно готов к переключению. |

Короче говоря, настройка поверх Blue заключается не в том, что «через несколько чатов стало лучше». Речь идет о том, чтобы поместить кандидата в Harness, собрать сопоставимые доказательства и позволить результатам ворот и готовности решить, действительно ли безопасно сохранить изменение.

## Особенности

| Особенность | Что это дает |
|---------|-------------------|
| Высокая доступность веб-поиска и среды выполнения в браузере | Одно из **самых ярких преимуществ** Blue. Blue объединяет **четыре пути доступа в Интернет** для поиска, чтения, извлечения и сканирования; сохраняет **три резервных уровня** для HTTP, извлечения прокси и сеансов браузера; обрабатывает **антиботовые страницы** с обнаружением проблем, повторным использованием файлов cookie/сессий, скрытностью и передачей управления браузером; и маршруты через **три браузерные системы**: `lightpanda`, управляемый Chromium и ретрансляционный/локальный Chromium. |
| Среда выполнения исследований «три в одном» | **Одна общедоступная исследовательская запись** может быть направлена ​​на `deep_research`, `analyze` и `ui_review`. Тот же набор открытий и доказательств затем создает **исследования с приоритетом цитирования**, **ограниченные отчеты** и **структурированные обзоры UI/UX/доступности**. |
| Harness Среда выполнения, оценки и развития | Делает оценку **примитивом времени выполнения** при разработке, обучении и производстве. Harness охватывает **регрессию и дымовые проверки**, оценку, базовые показатели, отчеты и проверку во время выполнения, а затем переносит те же доказательства в **эволюцию навыков**, последующую оценку, продвижение по службе или откат, а также `AGENTS.md` или рассмотрение предложений по инструкциям. |
| Мультимодальная среда выполнения с упором на собственные возможности | Сохраняет **голос, OCR, PDF, задачи браузера, преобразование документов, заполнение структурированных форм, обработку мультимедиа и генерацию мультимедиа** по **в первую очередь собственным и локальным путям**, с **маршрутизацией модели только тогда, когда это действительно необходимо**. |
| Безопасность и управление | Включает **выполнение в песочнице**, **защиту от быстрого внедрения**, **аудит сеансов**, разрешения, **RBAC**, **WebAuthn**, оперативные защитные меры и **проверку навыков безопасности**. |
| LLM Wiki и пространство знаний | Превращает результаты памяти, исследований и выполнения во время выполнения в **поверхность знаний, подобную вики**, с **страницами сводки**, индексами, **обратными ссылками**, **свежестью** и **рабочими процессами архивирования**. |
| Магазин навыков и торговая площадка | Предоставляет **встроенные функции обнаружения навыков**, курирования, синхронизации и **локального сканирования**, поэтому расширяемость доступна **с первого дня**. |
| Пул поставщиков производственного уровня | Предоставляет настоящий пул поставщиков с **проверками работоспособности**, **автоматическим переключением при сбое**, **автоматическими выключателями** и **гонками поставщиков** для длительных рабочих нагрузок. |
| Встроенная локальная среда выполнения малых моделей | Предоставляет встроенную среду выполнения **`Qwen3.5-0.8B` + `llama.cpp`** для **локальных коротких вопросов и ответов**, распознавания изображений, маршрутизации инструментов, обобщения, **сжатия контекста** и **предварительной обработки документов**. |
| Долговечная надежность | Считает **OTA обновления**, **резервное копирование и восстановление**, **горячую перезагрузку конфигурации** и **восстановление после сбоя** как **встроенные эксплуатационные проблемы**. |
