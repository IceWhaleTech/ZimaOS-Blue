## 模板规范

每份 PRD 应遵循以下结构：

1. **概览（Overview）** - 对功能的简要描述  
2. **目标（Goals）** - 希望达成的结果  
3. **用户故事（User Stories）** - 谁需要这个功能，以及为什么  
4. **需求（Requirements）** - 功能性与非功能性需求  
5. **技术设计（Technical Design）** - 高层技术方案  
6. **里程碑（Milestones）** - 实施阶段划分  
7. **成功指标（Success Metrics）** - 如何衡量成功  
8. **待决问题（Open Questions）** - 尚未确定的事项

## 状态说明

- `Draft` - 初稿，待评审  
- `In Review` - 评审中  
- `Approved` - 已批准，可进入实现  
- `In Progress` - 实现中  
- `Completed` - 功能已上线
