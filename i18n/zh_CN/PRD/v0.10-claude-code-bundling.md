# v0.10 Claude Code CLI 打包方案

[English Version](../../../PRD/v0.10-claude-code-bundling.md)

## 概述

本 PRD 定义了 Claude Code CLI 在 ZimaOS-Echo 中的打包和管理方式。目标是提供开箱即用的体验，同时保持不同部署场景的灵活性。

## 目标

1. **最小二进制体积** - 默认不嵌入 CLI，保持 Echo 二进制文件较小 (~50MB)
2. **零配置部署** - CLI 在首次使用时自动下载
3. **灵活部署** - 支持嵌入和下载两种 CLI 模式
4. **版本管理** - 用户可在设置中查看和更新 CLI 版本
5. **自动更新** - 可选的自动版本检查和更新
6. **系统 CLI 支持** - 如果系统已安装 CLI 且验证通过，可直接使用

## 二进制解析顺序

解析 Claude Code CLI 二进制文件时，系统按以下优先级：

1. **嵌入的二进制** - 如果当前平台有嵌入的，解压并使用
2. **已下载的二进制** - 如果之前下载过，使用缓存版本
3. **系统 PATH** - 如果允许且验证通过，使用系统安装的 CLI
4. **从 GCS 下载** - 作为后备方案下载最新版本

### 系统 CLI 验证

使用系统安装的 CLI 时，系统会执行：

1. **版本检查** - 执行 `claude --version` 获取版本字符串
2. **Dry run 验证** - 执行 `claude --help` 验证是否为真正的 Claude Code CLI
3. **最新版本检查** (可选) - 如果启用了 `require_latest`，验证版本是否为最新

这确保只使用真正的 Claude Code CLI 二进制文件，防止 PATH 中的恶意二进制文件带来的安全问题。

## 打包模式

### 模式 1: 按需下载 (默认)

CLI 在首次使用时或明确请求时下载。

**特点:**
- 初始二进制文件较小 (~50MB)
- 首次使用需要网络
- 始终获取最新 CLI 版本
- 适合大多数部署场景

**构建命令:**
```bash
# 不嵌入 CLI 构建 (默认)
make build
```

### 模式 2: 嵌入式 (可选)

Claude Code CLI 二进制文件在构建时嵌入到 Echo 二进制文件中。

**特点:**
- 单文件部署
- 启动时无需网络
- 二进制文件较大 (~170-220MB，取决于平台)
- CLI 版本在构建时固定

**构建命令:**
```bash
# 仅嵌入当前平台的 CLI 构建
EMBED_CLAUDE_CODE=true make build

# 嵌入指定平台的 CLI 构建
EMBED_CLAUDE_CODE=true EMBED_PLATFORM=linux-arm64 make build

# 嵌入所有平台的 CLI 构建 (用于分发)
EMBED_CLAUDE_CODE=true EMBED_ALL_PLATFORMS=true make build
```

## 配置

### 配置文件 (`config.yaml`)

```yaml
claudecode:
  enabled: true

  # 打包配置
  bundling:
    # 模式: "embedded" | "download" | "system" | "auto"
    # - embedded: 仅使用嵌入的二进制文件
    # - download: 始终下载，不使用嵌入的或系统的
    # - system: 优先使用系统 CLI（如果可用且验证通过）
    # - auto: 优先嵌入的，然后系统的，最后下载 (默认)
    mode: "auto"

    # 系统 CLI 设置
    system:
      allow: true              # 允许使用系统安装的 CLI
      require_latest: false    # 仅当系统 CLI 是最新版本时才使用
      validate: true           # 使用前通过 dry run 验证系统 CLI

    # 自动更新设置
    auto_update:
      enabled: false           # 启用自动更新
      check_interval: "24h"    # 检查更新的频率
      channel: "stable"        # 发布渠道: "stable" | "beta"

    # 下载设置 (当模式为 "download" 或 "auto" 时)
    download:
      base_url: "https://storage.googleapis.com/claude-code-dist-86c565f3-f756-42ad-8dfa-d59b1c096819/claude-code-releases"
      cache_dir: ""            # 空 = ~/.local/share/zimaos-echo/claude-code
      verify_checksum: true    # 下载后验证 SHA256 校验和
      timeout: "5m"            # 下载超时

    # 版本锁定 (可选)
    version: ""                # 空 = 最新版，或指定版本如 "2.1.22"
```

### 环境变量

| 变量 | 描述 | 默认值 |
|------|------|--------|
| `ECHO_CC_MODE` | 打包模式覆盖 | `auto` |
| `ECHO_CC_VERSION` | 锁定到指定版本 | (最新) |
| `ECHO_CC_AUTO_UPDATE` | 启用自动更新 | `false` |
| `ECHO_CC_CACHE_DIR` | 自定义缓存目录 | `~/.local/share/zimaos-echo/claude-code` |
| `ECHO_CC_ALLOW_SYSTEM` | 允许系统 CLI | `true` |
| `ECHO_CC_REQUIRE_LATEST` | 系统 CLI 需要最新版本 | `false` |

## 版本管理

### 版本信息

系统跟踪:
- **嵌入版本**: 构建时打包的版本 (如果有)
- **已安装版本**: 当前安装/解压的版本
- **系统版本**: 系统安装的 CLI 版本 (如果有)
- **最新版本**: 发布渠道中的最新可用版本
- **活动版本**: 当前使用的版本

## API 端点

### 版本管理

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | `/api/v1/claudecode/version` | 获取版本信息 |
| POST | `/api/v1/claudecode/version/check` | 检查更新 |
| POST | `/api/v1/claudecode/version/update` | 更新到指定版本 |
| POST | `/api/v1/claudecode/validate` | 验证 CLI 二进制文件 |
| POST | `/api/v1/claudecode/cache/clear` | 清除下载缓存 |
| GET | `/api/v1/claudecode/version/history` | 获取版本历史 |

## 构建系统变更

### Makefile 更新

```makefile
# 嵌入选项 (默认: 不嵌入)
EMBED_CLAUDE_CODE ?= false
EMBED_PLATFORM ?= $(shell go env GOOS)-$(shell go env GOARCH | sed 's/amd64/x64/')
EMBED_ALL_PLATFORMS ?= false

# 下载 Claude Code CLI 用于嵌入 (仅当 EMBED_CLAUDE_CODE=true 时)
download-claude-code:
ifeq ($(EMBED_CLAUDE_CODE),true)
ifeq ($(EMBED_ALL_PLATFORMS),true)
	@$(PROJECT_ROOT)/scripts/download-claude-code.sh --all
else
	@$(PROJECT_ROOT)/scripts/download-claude-code.sh --platform $(EMBED_PLATFORM)
endif
else
	@echo "跳过 Claude Code CLI 嵌入 (EMBED_CLAUDE_CODE=false)"
	@echo "CLI 将在首次使用时下载"
	@mkdir -p $(CLAUDE_CODE_DIR)
	@touch $(CLAUDE_CODE_DIR)/.gitkeep
endif
```

### 下载脚本更新

```bash
#!/bin/bash
# scripts/download-claude-code.sh

# 解析参数
PLATFORM=""
ALL_PLATFORMS=false

while [[ $# -gt 0 ]]; do
    case $1 in
        --platform)
            PLATFORM="$2"
            shift 2
            ;;
        --all)
            ALL_PLATFORMS=true
            shift
            ;;
        *)
            shift
            ;;
    esac
done

# 如果指定了特定平台，只下载那一个
if [ -n "$PLATFORM" ]; then
    PLATFORMS=("$PLATFORM")
elif [ "$ALL_PLATFORMS" = true ]; then
    PLATFORMS=("darwin-arm64" "darwin-x64" "linux-arm64" "linux-x64" "win32-x64")
else
    # 默认: 仅当前平台
    PLATFORMS=("$(get_current_platform)")
fi
```

## 安全考虑

1. **校验和验证**: 下载后始终验证 SHA256 校验和
2. **仅 HTTPS**: 仅从官方 HTTPS 端点下载
3. **签名验证**: (未来) 验证二进制签名
4. **沙箱执行**: 在沙箱环境中运行 CLI
5. **版本锁定**: 允许锁定到特定版本以保持稳定性

## 回滚策略

如果更新导致问题:

1. **自动回滚**: 如果更新后 CLI 无法启动，恢复到之前的版本
2. **手动回滚**: 用户可以从历史记录中选择之前的版本
3. **嵌入回退**: 如果一切都失败，回退到嵌入的版本

## 非功能性需求

| 需求 | 目标 |
|------|------|
| 下载超时 | < 5 分钟 |
| 版本检查延迟 | < 2 秒 |
| 二进制解压时间 | < 5 秒 |
| 设置页面加载时间 | < 500ms |
| 更新通知延迟 | < 1 秒 |
