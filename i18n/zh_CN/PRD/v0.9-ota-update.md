## 1. 概述

### 1.1 背景

ZimaOS-Echo 是一个运行在 NAS 设备上的单二进制 Go 服务。目前，用户必须手动下载并替换二进制文件来更新服务，这既不方便又容易出错。OTA（空中下载）更新系统将通过实现自动更新并最大限度减少服务中断，显著改善用户体验。

### 1.2 目标

1. 实现自动版本检查和更新通知
2. 支持热更新，保持运行时间连续性（无需重启服务）
3. 提供更新失败时的回滚能力
4. 通过校验和验证和签名发布维护安全性
5. 支持多个发布渠道（stable、beta、alpha）

### 1.3 非目标

1. 完整系统更新（仅限 ZimaOS-Echo 二进制文件）
2. 主要版本之间的配置迁移
3. 多节点集群更新（仅限单实例）

### 4.4 热更新实现

#### 4.4.1 Linux / macOS（使用 syscall.Exec）

```go
func (u *Updater) hotUpdateUnix() error {
    // 1. 备份当前二进制文件
    os.Rename(currentBinary, currentBinary+".backup")

    // 2. 替换二进制文件（原子重命名）
    os.Rename(newBinary, currentBinary)

    // 3. 准备运行时间连续性的环境变量
    env := append(os.Environ(), fmt.Sprintf("ECHO_START_TIME=%d", u.startTime.Unix()))

    // 4. 执行新二进制文件（原地替换当前进程）
    return syscall.Exec(currentBinary, os.Args, env)
}
```

#### 4.4.2 Windows（重命名 + 新进程）

Windows 无法替换运行中的 exe，但允许重命名：

```go
func (u *Updater) hotUpdateWindows() error {
    // 1. 重命名当前运行的 exe（Windows 允许此操作）
    os.Rename(currentBinary, currentBinary+".old")

    // 2. 将新版本移动到原位置
    os.Rename(newBinary, currentBinary)

    // 3. 启动新进程，传递 uptime 环境变量
    cmd := exec.Command(currentBinary, os.Args[1:]...)
    cmd.Env = append(os.Environ(), fmt.Sprintf("ECHO_START_TIME=%d", u.startTime.Unix()))
    cmd.Start()

    // 4. 退出当前进程
    os.Exit(0)
    return nil
}

// 新进程启动时清理旧二进制文件
func cleanupOldBinary() {
    if _, err := os.Stat(currentBinary + ".old"); err == nil {
        os.Remove(currentBinary + ".old")
    }
}
```

#### 4.4.3 运行时间保持

```go
func getStartTime() time.Time {
    // 检查是否从热更新恢复
    if startTimeStr := os.Getenv("ECHO_START_TIME"); startTimeStr != "" {
        if ts, err := strconv.ParseInt(startTimeStr, 10, 64); err == nil {
            return time.Unix(ts, 0)
        }
    }
    // 全新启动
    return time.Now()
}

func getUptime() time.Duration {
    return time.Since(startTime)
}
```

#### 4.4.4 优雅重启（回退方案）

```go
func (u *Updater) gracefulRestart() error {
    // 1. 停止接受新连接
    u.server.SetReady(false)

    // 2. 等待现有连接排空
    ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
    defer cancel()

    if err := u.server.DrainConnections(ctx); err != nil {
        log.Warn().Err(err).Msg("部分连接未能及时排空")
    }

    // 3. 启动新进程
    cmd := exec.Command(u.binaryPath, os.Args[1:]...)
    cmd.Env = append(os.Environ(),
        fmt.Sprintf("ECHO_START_TIME=%d", u.startTime.Unix()),
    )
    cmd.Stdout = os.Stdout
    cmd.Stderr = os.Stderr

    if err := cmd.Start(); err != nil {
        return err
    }

    // 4. 退出当前进程
    os.Exit(0)
    return nil
}
```

### 4.5 安全性

1. **仅 HTTPS**: 所有下载使用 HTTPS
2. **校验和验证**: 应用前验证 SHA256 校验和
3. **签名验证**（P2）: 发布版本的 GPG 签名验证
4. **最小权限**: 更新进程以最小所需权限运行
5. **原子更新**: 二进制文件替换使用原子重命名操作
