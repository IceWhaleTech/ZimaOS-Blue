## 概述

Echo Companion 是一款实时监控工具，为开发者和运维人员提供一个可视化界面，用于观察 AI Agent 在多平台上的运行情况。它参考了 [Crabwalk](https://github.com/luccast/crabwalk) 的设计理念，并结合 ZimaOS-Echo 的安全能力（如安全检查、审计日志、沙箱），提供一个**安全、可观测、可审计**的 Agent 监控解决方案。

### 核心价值

1. **实时可观测性**：实时追踪 Agent 会话、工具调用与决策链路
2. **安全审计**：与 Echo 安全层集成，提供威胁检测与异常行为告警
3. **多平台监控**：统一监控 WhatsApp、Telegram、Discord、Slack、Matrix、飞书等渠道上的 Agent 行为
4. **调试友好**：帮助开发者快速定位问题、分析上下文并优化 Agent 行为

## 用户故事

### Story 1：实时活动监控

**作为** 系统管理员  
**我希望** 能实时查看所有 Agent 活动状态  
**从而** 能够及时发现异常并采取措施  

**验收标准：**
- [ ] 能够可视化当前所有活跃的 Agent 会话
- [ ] 实时更新会话状态和工具调用信息
- [ ] 支持按平台、用户、时间进行筛选
- [ ] 显示会话的安全评分与威胁等级

### Story 2：安全威胁告警

**作为** 安全工程师  
**我希望** 在检测到 Prompt Injection 或异常行为时收到告警  
**从而** 能快速响应安全事件  

**验收标准：**
- [ ] 集成 Prompt Guard 的威胁检测结果
- [ ] 实时展示威胁等级（None/Low/Medium/High/Critical）
- [ ] 支持配置告警阈值与通知方式
- [ ] 提供威胁详情与推荐处置动作

### Story 3：会话调试与回放

**作为** 开发者  
**我希望** 能够回放和分析历史会话  
**从而** 调试并优化 Agent 行为  

**验收标准：**
- [ ] 支持按时间轴回放会话
- [ ] 展示完整的工具调用链与参数
- [ ] 展示 LLM 输入/输出与 Token 消耗情况
- [ ] 支持导出会话数据用于离线分析

### Story 4：操作链路可视化

**作为** 开发者  
**我希望** 能以图形化方式查看 Agent 操作链路  
**从而** 理解 Agent 的决策过程  

**验收标准：**
- [ ] 使用流程图展示操作链路
- [ ] 支持展开节点查看详细参数

### 数据存储

遵循 NFR-006，所有数据采用**人类可读的纯文本文件**形式存储：

```text
data/companion/
├── sessions/
│   ├── 2026-01-28/
│   │   ├── session-abc123.jsonl      # 每行一个 JSON 对象
│   │   └── session-def456.jsonl
│   └── 2026-01-27/
│       └── ...
├── alerts/
│   ├── 2026-01-28.jsonl              # 每日告警日志
│   └── 2026-01-27.jsonl
└── stats/
    └── daily-stats.json              # 汇总统计
```

**文件格式（JSONL）：**
- 每行一个 JSON 对象，便于流式处理与 tail/grep
- 人类可读，便于直接排查
- 无需数据库依赖

### 数据模型

#### 会话事件 `SessionEvent`

```go
type SessionEvent struct {
    ID          string           `json:"id"`
    SessionID   string           `json:"session_id"`
    Timestamp   time.Time        `json:"timestamp"`
    EventType   SessionEventType `json:"event_type"`
    Platform    string           `json:"platform"`    // whatsapp, telegram, discord 等
    UserID      string           `json:"user_id"`
    TenantID    string           `json:"tenant_id,omitempty"`

    // 事件具体数据
    Message     *MessageEvent    `json:"message,omitempty"`
    ToolCall    *ToolCallEvent   `json:"tool_call,omitempty"`
    LLMRequest  *LLMRequestEvent `json:"llm_request,omitempty"`
    Security    *SecurityEvent   `json:"security,omitempty"`

    // 元数据
    Duration    time.Duration    `json:"duration,omitempty"`
    Status      string           `json:"status"`
    Error       string           `json:"error,omitempty"`
}

type SessionEventType string

const (
    EventSessionStart    SessionEventType = "session_start"
    EventSessionEnd      SessionEventType = "session_end"
    EventMessageReceived SessionEventType = "message_received"
    EventMessageSent     SessionEventType = "message_sent"
    EventToolCall        SessionEventType = "tool_call"
    EventLLMRequest      SessionEventType = "llm_request"
    EventSecurityThreat  SessionEventType = "security_threat"
    EventSandboxExec     SessionEventType = "sandbox_exec"
)
```

#### 安全事件 `SecurityEvent`

```go
type SecurityEvent struct {
    ThreatLevel      string   `json:"threat_level"`     // none, low, medium, high, critical
    ThreatScore      int      `json:"threat_score"`
    ThreatTypes      []string `json:"threat_types"`
    DetectedPatterns []string `json:"detected_patterns"`
    Action           string   `json:"action"`           // allowed, blocked, filtered
    FilteredContent  string   `json:"filtered_content,omitempty"`
}
```

#### 工具调用事件 `ToolCallEvent`

```go
type ToolCallEvent struct {
    ToolName   string                 `json:"tool_name"`
    ToolID     string                 `json:"tool_id"`
    Input      map[string]interface{} `json:"input"`
    Output     interface{}            `json:"output,omitempty"`
    Duration   time.Duration          `json:"duration"`
    Status     string                 `json:"status"`
    SandboxUsed bool                  `json:"sandbox_used"`
    Resources  *ResourceUsage         `json:"resources,omitempty"`
}

type ResourceUsage struct {
    CPUTime    time.Duration `json:"cpu_time"`
    MemoryPeak int64         `json:"memory_peak"`
    IORead     int64         `json:"io_read"`
    IOWrite    int64         `json:"io_write"`
}
```

## 安全集成

### Prompt Guard 集成示例

```go
func (s *CompanionService) OnPromptGuardResult(
    sessionID string,
    input string,
    result *promptguard.CheckResult,
) {
    if result.IsThreat {
        s.EmitEvent(SessionEvent{
            SessionID: sessionID,
            EventType: EventSecurityThreat,
            Security: &SecurityEvent{
                ThreatLevel:      result.ThreatLevel.String(),
                ThreatScore:      result.Score,
                ThreatTypes:      result.ThreatTypes,
                DetectedPatterns: result.Patterns,
                Action:           "blocked",
            },
        })

        if result.ThreatLevel >= promptguard.ThreatHigh {
            s.alertEngine.Trigger(Alert{
                Severity:  "high",
                Title:     "High-severity prompt injection detected",
                SessionID: sessionID,
                Details:   result,
            })
        }
    }
}
```

### 审计日志集成

```go
func (s *CompanionService) SubscribeAuditEvents() {
    s.auditSubscriber.Subscribe(func(entry *audit.Entry) {
        event := s.convertAuditEntry(entry)
        s.EmitEvent(event)
    })
}
```

### 沙箱监控集成

```go
func (s *CompanionService) OnSandboxExecution(
    sessionID string,
    exec *sandbox.Execution,
) {
    s.EmitEvent(SessionEvent{
        SessionID: sessionID,
        EventType: EventSandboxExec,
        ToolCall: &ToolCallEvent{
            ToolName:    exec.Command,
            SandboxUsed: true,
            Duration:    exec.Duration,
            Status:      exec.Status,
            Resources: &ResourceUsage{
                CPUTime:    exec.CPUTime,
                MemoryPeak: exec.MemoryPeak,
            },
        },
    })
}
```

## 安全考量

### 认证与鉴权
- 复用 Echo 现有 OIDC 认证体系
- 基于角色的访问控制（RBAC）：
  - `companion:read` —— 只能查看会话与事件
  - `companion:admin` —— 管理告警、配置与导出
- 多租户隔离：不同租户的会话与事件互相不可见

### 数据隐私
- 支持敏感数据脱敏（如 API Key、密码等）
- 可配置的数据保留策略（会话/事件/告警）
- 支持数据导出与删除（满足合规要求）

### 威胁检测增强
- 异常行为检测：
  - 工具调用频率异常
  - 会话时长异常
  - 资源占用异常
- 跨会话关联分析：
  - 同源攻击行为聚合
  - 分布式攻击模式识别
- 实时威胁情报：
  - 聚合威胁检测结果
  - 生成威胁趋势报告
