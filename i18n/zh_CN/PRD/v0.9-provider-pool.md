# PRD: Provider 池化 - 统一 LLM 提供商管理

**版本**: 0.9.3
**作者**: ZimaOS-Echo 团队
**状态**: 草稿
**创建日期**: 2026-01-28

---

## 1. 概述

### 1.1 背景

ZimaOS-Echo 目前支持多个 LLM 提供商（OpenAI、Anthropic、Ollama 等），但每个提供商都是独立配置的。用户通常通过不同渠道访问多个 AI 服务：

- 直接 API 订阅（OpenAI、Anthropic、Google）
- 本地 IDE 集成（Antigravity、Cursor、Windsurf）
- 第三方聚合器（OpenRouter、AiHubMix）
- 自托管模型（Ollama、vLLM）

Provider 池化系统将统一这些多样化的来源，实现跨所有可用 LLM 资源的智能路由、负载均衡和成本优化。

### 1.2 目标

1. 提供统一接口管理多个 LLM 提供商
2. 支持复用本地 IDE 工具的凭证（Antigravity、Cursor 等）
3. 基于可用性、成本和性能实现智能模型路由
4. 支持 OpenAI 兼容 API 的自定义提供商
5. 提供每个提供商的使用量跟踪和配额管理
6. 支持 ACP（Agent Communication Protocol）提供商以扩展能力

### 1.3 非目标

1. 构建新的 LLM 推理引擎
2. 模型微调或训练
3. 提供商计费集成（仅跟踪，不支付）

## 2. 用户故事

### 2.1 作为用户

- 我希望将现有的 Antigravity/Cursor 订阅连接到 Echo
- 我希望在一个地方看到所有提供商的所有可用模型
- 我希望 Echo 自动为我的任务选择最佳可用模型
- 我希望跟踪不同提供商的使用情况

### 2.2 作为管理员

- 我希望为同一提供商配置多个 API 密钥（负载均衡）
- 我希望设置每个提供商的使用限制以控制成本
- 我希望优先使用某些提供商
- 我希望添加自定义 OpenAI 兼容端点

### 2.3 作为开发者

- 我希望轻松添加新的提供商集成
- 我希望实现自定义路由策略
- 我希望访问提供商健康指标

### 4.2 数据模型

```go
// Provider 表示 LLM 提供商配置
type Provider struct {
    ID          string          `json:"id"`
    Name        string          `json:"name"`
    Type        ProviderType    `json:"type"`        // builtin, custom, acp, ide
    Enabled     bool            `json:"enabled"`
    Status      ProviderStatus  `json:"status"`      // active, inactive, error
    BaseURL     string          `json:"base_url,omitempty"`
    APIKeys     []APIKey        `json:"api_keys,omitempty"`
    Priority    int             `json:"priority"`    // 越高越优先
    CreatedAt   time.Time       `json:"created_at"`
    UpdatedAt   time.Time       `json:"updated_at"`
}

// Model 表示提供商的可用模型
type Model struct {
    ID           string            `json:"id"`
    ProviderID   string            `json:"provider_id"`
    Name         string            `json:"name"`
    DisplayName  string            `json:"display_name"`
    Enabled      bool              `json:"enabled"`
    Capabilities ModelCapabilities `json:"capabilities"`
    InputPrice   float64           `json:"input_price,omitempty"`
    OutputPrice  float64           `json:"output_price,omitempty"`
    ContextWindow int              `json:"context_window,omitempty"`
}

type ModelCapabilities struct {
    Chat          bool `json:"chat"`
    Vision        bool `json:"vision"`
    FunctionCall  bool `json:"function_call"`
    Streaming     bool `json:"streaming"`
    Thinking      bool `json:"thinking"`      // 扩展思考模式
}
```

```yaml
provider_pool:
  enabled: true

  health_check:

    enabled: true
```

## 5. 安全考虑

- API 密钥使用 AES-256-GCM 加密存储
- 密钥永不在 API 响应中暴露
- IDE 集成需要用户同意
- 所有提供商连接使用 HTTPS
