### 支持的文档类型（Supported Document Types）

| 类型 | 扩展名 | 解析器 |
|------|--------|--------|
| PDF | `.pdf` | pdfcpu / unipdf |
| Word | `.docx` | unioffice |
| 文本 | `.txt` | 原生 |
| Markdown | `.md` | 原生 |
| HTML | `.html` | goquery |
| CSV | `.csv` | 原生 |

### 向量嵌入模型（Embedding Models）

| 模型 | 维度 | 备注 |
|------|------|------|
| OpenAI text-embedding-3-small | 1536 | 云端 |
| OpenAI text-embedding-3-large | 3072 | 云端 |
| Ollama nomic-embed-text | 768 | 本地 |
| Ollama mxbai-embed-large | 1024 | 本地 |

### 向量数据库选型（Vector Database Options）

| 数据库 | 优点 | 缺点 |
|--------|------|------|
| SQLite-vec | 嵌入式，简单 | 可扩展性有限 |
| Qdrant | 功能丰富，性能好 | 需独立服务 |
| Milvus | 企业级 | 部署复杂 |
| Chroma | 偏 Python 生态 | 非 Go 原生 |
