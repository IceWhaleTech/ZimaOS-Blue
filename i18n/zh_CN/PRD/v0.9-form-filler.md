**状态**: 草稿

## 1. 概述

### 1.1 背景

用户经常遇到需要重复输入数据的网页表单——注册表单、结账页面、个人资料设置等。虽然浏览器自动填充可以处理基本字段，但在以下场景表现不佳：

- 非标准字段名或自定义表单实现
- 需要特定格式的字段（日期、电话号码、身份证号）
- 基于表单用途的上下文感知填充
- 密码字段隐藏输入，难以验证是否正确

智能表单填写助手将提供一个智能悬浮插件，通过多种检测方法识别表单字段并准确填充。

### 1.2 目标

1. 提供可在任何网页上激活的悬浮插件
2. 使用多种策略智能检测表单字段（标签、占位符、模式）
3. 支持格式模板和基于样例的字段识别
4. 自动显示密码字段以便提交前验证
5. 从用户修正中学习以提高准确性

### 1.3 非目标

1. 替代浏览器内置密码管理器
2. 存储敏感凭证（密码、信用卡）- 交给浏览器处理
3. 未经用户确认的自动表单提交
4. 验证码破解或类机器人行为

## 2. 用户故事

### 2.1 作为用户

- 我希望有一个悬浮按钮，点击即可自动填充表单
- 我希望插件能识别非标准命名的字段
- 我希望在提交前看到密码字段中填写的内容
- 我希望提供样例数据后，类似字段能被自动检测
- 我希望修正错误填充后，系统能从中学习

### 2.2 作为高级用户

- 我希望为特定网站定义自定义字段模式
- 我希望为不同场景创建填充模板（工作、个人）
- 我希望使用快捷键触发表单填充
- 我希望导出/导入我的填充配置

## 3. 功能需求

### 3.1 悬浮插件

| ID | 需求 | 优先级 |
|----|------|--------|
| FR-001 | 在网页上显示可拖动的悬浮插件 | P0 |
| FR-002 | 插件应可最小化和重新定位 | P0 |

### 3.2 字段检测

| ID | 需求 | 优先级 |
|----|------|--------|
| FR-006 | 通过标准 HTML 属性检测字段（name、id、type） | P0 |
| FR-007 | 通过标签文本和占位符检测字段 | P0 |
| FR-008 | 通过与标签的视觉距离检测字段 | P1 |
| FR-009 | 通过格式模式检测字段（邮箱、电话、日期） | P0 |
| FR-010 | 支持自定义标记识别（如 `data-autofill`） | P1 |
| FR-011 | 使用 LLM 进行模糊字段分类 | P2 |

### 4.2 配置

```yaml
form_filler:
  enabled: true

  widget:
    default_position: "bottom-right"
    keyboard_shortcut: "Ctrl+Shift+F"
    auto_show_on_forms: true

  password:
    auto_reveal: true
    reveal_timeout: 5s
    show_indicator: true

  detection:
    use_llm_fallback: true
    confidence_threshold: 0.7
```

## 6. 安全考虑

- 模板本地存储，未经同意不发送到外部服务器
- 密码值永不记录或存储
- 站点映射仅包含字段类型，不含实际值
- LLM 字段分类仅发送字段元数据，不含值
