## 1. 概览

### 1.1 背景

用户在日常使用网页时，经常会遇到各种表单：注册、结账、个人资料设置等。浏览器自带的自动填充在简单场景下尚可，但在下面这些情况表现较差：

- 非标准字段命名或自定义表单实现
- 需要特定格式的字段（日期、手机号、证件号等）
- 需要根据表单用途进行上下文感知的填充
- 密码字段被隐藏，用户难以在提交前确认填入内容

因此，需要一个**智能表单填充小组件**：可以在任意网页上悬浮、识别表单字段，并进行更智能、更可控的填充。

### 1.2 目标

1. 提供一个可以在任意网页上激活的悬浮小组件
2. 通过多种策略智能检测表单字段（标签、占位符、模式等）
3. 支持模板与示例驱动的字段识别与填充
4. 在提交前临时展示密码字段内容，方便用户确认
5. 从用户修正行为中学习，不断提高填充准确率

### 1.3 非目标

1. 替代浏览器内置的密码管理器
2. 存储敏感凭据（密码、信用卡号等）——这一类数据交给浏览器处理
3. 在用户未确认的情况下自动提交表单
4. 绕过验证码或实现类似机器人的行为

## 2. 用户故事

### 2.1 作为普通用户

- 我希望在页面上有一个悬浮按钮，点击即可自动填充表单
- 我希望它能识别非标准命名的字段
- 我希望在提交前能看到被填入的密码内容
- 我希望可以提供示例数据，让相似字段自动识别并填充
- 我希望当填错时可以手动修正，并让系统「记住」哪种字段应该如何填

### 2.2 作为高级用户

- 我希望能为特定网站定义自定义字段模式
- 我希望能为不同场景创建不同的填充模板（工作/个人等）
- 我希望有快捷键触发表单填充
- 我希望可以导出/导入自己的填充配置

### 2.3 作为开发者

- 我希望能将该表单填充能力与 Echo 的 Agent 能力集成
- 我希望能够扩展自定义字段检测策略
- 我希望能访问填充历史以便调试问题

### 4.2 数据模型

```ts
// 字段检测结果
interface DetectedField {
  element: HTMLElement;
  fieldType: FieldType;
  confidence: number;
  detectionSource: 'attribute' | 'label' | 'pattern' | 'llm';
  suggestedValue?: string;
}

// 填充模板
interface FillTemplate {
  id: string;
  name: string;
  isDefault: boolean;
  fields: Record<string, string>;
  createdAt: Date;
  updatedAt: Date;
}

// 站点级映射
interface SiteMapping {
  domain: string;
  fieldMappings: Record<string, string>; // selector -> fieldType
  lastUsed: Date;
  userCorrections: number;
}

// 字段类型
type FieldType =
  | 'firstName' | 'lastName' | 'fullName'
  | 'email' | 'phone' | 'address'
  | 'city' | 'state' | 'zipCode' | 'country'
  | 'username' | 'password' | 'confirmPassword'
  | 'birthDate' | 'company' | 'title'
  | 'custom';
```

### 4.3 配置

```yaml
form_filler:
  enabled: true

  widget:
    default_position: "bottom-right"  # top-left, top-right, bottom-left, bottom-right
    keyboard_shortcut: "Ctrl+Shift+F"
    auto_show_on_forms: true

  password:
    auto_reveal: true
    reveal_timeout: 5s      # 自动恢复隐藏的时间
    show_indicator: true

  detection:
    use_llm_fallback: true
    confidence_threshold: 0.7
    scan_interval: 1000ms   # 支持 SPA 的重新扫描间隔

  learning:
    enabled: true
    sync_enabled: false
    max_site_mappings: 1000
```

## 6. 安全考虑

- 模板数据仅存储在本地，不会在未授权情况下发送至外部服务
- 密码字段的真实值**永不**被记录或持久化
- 站点映射只记录「字段类型」与「选择器」，不包含真实值
- LLM 字段分类仅发送字段元信息（标签/placeholder 等），不发送真实用户数据
- 用户可以完全关闭「学习」与「同步」能力
