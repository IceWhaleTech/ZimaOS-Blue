# v0.1.0 实施清单

[English Version](../../../../plan/DEV/v0.1.0-checklist.md)

## 目标

## 验收标准
- [ ] 能在 NAS 上运行 **24 小时不重启**

## 运行方式

### 后端
```bash
cd server
make deps    # 下载依赖
make test    # 运行测试
make build   # 构建二进制
make run     # 构建并运行
```

### 前端
```bash
cd web
npm install      # 安装依赖
npm run test:run # 运行测试
npm run dev      # 启动开发服务器
npm run build    # 构建生产版本
```

### 文档站点
```bash
cd docs-site
npm install      # 安装依赖
npm run dev      # 启动开发服务器
npm run build    # 构建静态站点
```
