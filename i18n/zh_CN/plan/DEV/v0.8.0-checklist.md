# v0.8.0 实现清单

[English Version](../../../../plan/DEV/v0.8.0-checklist.md)

本清单跟踪 v0.8.0（性能优化）的实现进度。

## 目标
全面的性能调优与优化 - 提升系统吞吐量、降低延迟、优化资源使用，并建立性能基准测试基础设施。

## 验收标准
- [ ] 数据库查询性能提升 30%+
- [ ] 内存使用降低 20%+
- [ ] P99 延迟降低 25%+
- [ ] 建立完整的基准测试套件
- [ ] 所有优化都有单元测试
- [ ] CI/CD 中集成性能回退检测

## 配置

### 新配置选项
```yaml
# v0.8 config.yaml 新增

# 性能配置
performance:
  # 数据库优化
  database:
    pool_size: 10
    max_idle_conns: 5
    conn_max_lifetime: 1h
    wal_mode: true
    cache_size: 10000  # 页数
    page_size: 4096
    checkpoint_interval: 5m
    batch_size: 1000

  # 内存优化
  memory:
    gogc: 100
    gomemlimit: 512MB
    buffer_pool_size: 1000
    object_pool_size: 500

  # 并发
  concurrency:
    worker_pool_size: 100
    max_goroutines: 10000
    channel_buffer_size: 100

  # 网络
  network:
    http2_enabled: true
    keep_alive_timeout: 30s
    compression_enabled: true
    compression_level: 6
    request_timeout: 30s
    retry_max_attempts: 3
    retry_backoff_base: 100ms

  # 缓存
  cache:
    l1_enabled: true
    l1_size: 1000
    l1_ttl: 5m
    l2_enabled: true
    l2_path: "./cache"
    l2_size: 100MB
    l2_ttl: 1h
    eviction_policy: "lru"  # lru, lfu

  # 性能分析
  profiling:
    pprof_enabled: true
    pprof_path: "/debug/pprof"
    metrics_enabled: true
    benchmark_enabled: false
```

## API 端点（新增）

|------|------|------|
| GET | `/debug/pprof/` | pprof 索引 |
| GET | `/debug/pprof/heap` | 堆分析 |

| GET | `/debug/pprof/profile` | CPU 分析 |
| GET | `/api/v1/metrics/performance` | 性能指标 |
| GET | `/api/v1/cache/stats` | 缓存统计 |
| POST | `/api/v1/cache/clear` | 清除缓存 |
| GET | `/api/v1/pool/stats` | 池统计 |
