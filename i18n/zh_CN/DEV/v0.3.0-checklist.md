## 配置

### 新配置选项
```yaml
# v0.3 config.yaml 新增

# 资源限制
resources:
  max_memory_mb: 512
  max_cpu_percent: 50
  max_open_files: 65536
  max_goroutines: 10000
  gc_percent: 100

# Cgroup v2 配置（仅 Linux）
cgroup:
  enabled: false
  cgroup_root: "/sys/fs/cgroup"
  cgroup_name: "zimaos-echo"
  io:
    enabled: false
    read_bps: 0           # 最大读取字节/秒（0 = 无限制）
    write_bps: 0          # 最大写入字节/秒（0 = 无限制）
    read_iops: 0          # 最大读取 IOPS（0 = 无限制）
    write_iops: 0         # 最大写入 IOPS（0 = 无限制）
    devices: []           # 设备 major:minor 列表
  memory:
    enabled: false
    max_bytes: 0
    high_bytes: 0
    swap_max_bytes: 0
  cpu:
    enabled: false
    max_percent: 0
    weight: 100

# 文件监视器
watcher:
  enabled: false
  paths:
    - /data/watch
  events:
    - create
    - modify
  recursive: true
  debounce_ms: 100
  ignore_patterns: []

# 任务调度器
scheduler:
  enabled: true
  max_concurrent: 10
  persistence: true
  db_path: "./data/scheduler.db"

# 工作池
workers:
  io_pool_size: 4
  compute_pool_size: 8
```

## API 端点（新增）

| 方法 | 路径 | 描述 |
|------|------|------|

## Docker 命令

### 构建
```bash
# 构建镜像
docker build -t zimaos-echo:latest -f deploy/docker/Dockerfile .

# 多架构构建
docker buildx build --platform linux/amd64,linux/arm64 -t zimaos-echo:latest .
```

### 运行
```bash
# 使用 docker 运行
docker run -d \
  --name zimaos-echo \
  -p 8080:8080 \
  -v ./data:/app/data \
  -v ./config.yaml:/app/config.yaml \
  zimaos-echo:latest

# 使用 docker-compose 运行
docker-compose up -d
```

---

## systemd 命令

```bash
# 安装服务
sudo cp deploy/systemd/zimaos-echo.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable zimaos-echo
sudo systemctl start zimaos-echo

# 检查状态
sudo systemctl status zimaos-echo
sudo journalctl -u zimaos-echo -f
```
