# v0.6.0 实现清单

[English Version](../../../DEV/v0.6.0-checklist.md)

本清单跟踪 v0.6.0（消息通道与更多集成）的实现进度。

## 目标
多通道消息支持 - 使用户能够通过各种消息平台与 Agent 交互。

## 验收标准
- [x] 通道抽象接口完全实现
- [x] 至少 3 个消息通道正常工作
- [x] 所有通道支持流式响应
- [x] 通过配置文件配置通道
- [x] 所有通道实现都有单元测试

---

## 配置

### 新配置选项
```yaml
# v0.6 config.yaml 新增

# 通道配置
channels:
  # 全局设置
  enabled: true
  default_timeout_seconds: 30
  max_message_length: 4096

  # Telegram
  telegram:
    enabled: false
    bot_token: ""
    webhook_url: ""  # 可选，为空则使用长轮询
    allowed_users: []  # 空 = 允许所有
    allowed_groups: []

  # Discord
  discord:
    enabled: false
    bot_token: ""
    application_id: ""
    allowed_guilds: []
    allowed_users: []

  # Slack
  slack:
    enabled: false
    bot_token: ""
    app_token: ""  # 用于 Socket Mode
    signing_secret: ""
    allowed_channels: []
    allowed_users: []

  # 企业微信
  wechat_work:
    enabled: false
    corp_id: ""
    agent_id: ""
    secret: ""
    token: ""
    encoding_aes_key: ""
    callback_url: ""

  # 飞书
  feishu:
    enabled: false
    app_id: ""
    app_secret: ""
    verification_token: ""
    encrypt_key: ""

  # Matrix
  matrix:
    enabled: false
    homeserver: ""
    user_id: ""
    access_token: ""
    device_id: ""
    allowed_rooms: []

  # iMessage（仅 macOS）
  imessage:
    enabled: false
    database_path: "~/Library/Messages/chat.db"
    poll_interval_ms: 1000
    allowed_numbers: []  # 空 = 允许所有

  # WhatsApp
  whatsapp:
    enabled: false
    phone_number: ""
    session_path: "./data/whatsapp"
    allowed_numbers: []  # 空 = 允许所有

  # Signal
  signal:
    enabled: false
    phone_number: ""
    config_path: "./data/signal"
    allowed_numbers: []  # 空 = 允许所有
```

## 安全考虑

1. **Token 存储**：所有 Token 应安全存储（环境变量或加密配置）
2. **访问控制**：为用户/群组/频道实现白名单
3. **速率限制**：通过速率限制防止滥用
4. **输入验证**：清理所有传入消息
5. **审计日志**：记录所有通道活动
