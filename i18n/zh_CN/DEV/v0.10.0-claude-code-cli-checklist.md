# v0.10.0 Claude Code CLI 集成清单

[English Version](../../../DEV/v0.10.0-claude-code-cli-checklist.md)

本清单跟踪 Claude Code CLI 作为核心 LLM 后端的集成实现。

## 目标

用 Claude Code CLI 替换直接的 Anthropic API 调用，以利用其上下文工程能力：
- 自动文件读取和代码搜索
- 工具调用（Bash、Read、Write、Grep、Glob 等）
- 会话上下文管理
- 自动摘要和上下文压缩
- MCP（模型上下文协议）支持

## 为什么选择 Claude Code CLI？

| 功能 | 直接 API | Claude Code CLI |
|------|----------|-----------------|
| 上下文工程 | 手动 | 自动 |
| 文件操作 | 自定义实现 | 内置工具 |
| 代码搜索 | 自定义实现 | 内置 Grep/Glob |
| 会话管理 | 自定义实现 | 内置 |
| 上下文压缩 | 手动 | 自动摘要 |
| MCP 支持 | 否 | 是 |
| 工具生态 | 自定义 | 丰富的内置工具 |

## 配置示例

```yaml
# config.yaml
claudecode:
  enabled: true
  command: "claude"  # 或完整路径：/usr/local/bin/claude
  workspace_dir: "/data/workspace"
  default_model: "opus"
  timeout: 5m
  session_ttl: 24h

  backend:
    args:
      - "-p"
      - "--output-format"
      - "json"
      - "--dangerously-skip-permissions"
    resume_args:
      - "-p"
      - "--output-format"
      - "json"
      - "--dangerously-skip-permissions"
      - "--resume"
      - "{sessionId}"
    model_arg: "--model"
    model_aliases:
      opus: "opus"
      sonnet: "sonnet"
      haiku: "haiku"
    session_arg: "--session-id"
    session_mode: "always"
    system_prompt_arg: "--append-system-prompt"
    system_prompt_mode: "append"
    system_prompt_when: "first"
    serialize: true
```

## 安全考虑

1. **命令注入**：执行前验证所有参数
2. **路径遍历**：验证工作区目录
3. **环境变量**：执行前清除敏感环境变量
4. **进程隔离**：如果可能，在沙箱环境中运行 CLI
5. **会话安全**：静态加密会话数据
6. **超时强制**：始终强制超时以防止挂起
