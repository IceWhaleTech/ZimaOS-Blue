## 配置

### 新配置选项
```yaml
# v0.4 config.yaml 新增

# 插件系统
plugins:
  enabled: true
  directory: "./plugins"
  auto_load: true
  wasm_enabled: false
  wasm_memory_limit_mb: 64

# Skill Hub
skills:
  enabled: true
  manifest_dir: "./skills"
  builtin:
    weather: true
    search: true
    calculator: true

# 认证
auth:
  enabled: true
  jwt:
    secret: "${JWT_SECRET}"
    expiration: "24h"
    refresh_expiration: "168h"
  api_keys:
    enabled: true
    max_per_user: 10

# RBAC
rbac:
  enabled: true
  default_role: "user"
  roles:
    - name: admin
      permissions: ["*"]
    - name: user
      permissions: ["chat", "skills.execute"]
    - name: readonly
      permissions: ["chat.read", "skills.list"]
```

## API 端点（新增）

### 认证
| 方法 | 路径 | 描述 |
|------|------|------|
| POST | `/api/v1/auth/login` | 用户登录 |
| POST | `/api/v1/auth/logout` | 用户登出 |
| POST | `/api/v1/auth/refresh` | 刷新令牌 |
| GET | `/api/v1/auth/me` | 获取当前用户 |

### API Keys
| 方法 | 路径 | 描述 |
|------|------|------|
| GET | `/api/v1/apikeys` | 列出 API keys |
| POST | `/api/v1/apikeys` | 创建 API key |
| DELETE | `/api/v1/apikeys/:id` | 删除 API key |

### 插件
| 方法 | 路径 | 描述 |
|------|------|------|
| GET | `/api/v1/plugins` | 列出插件 |
| GET | `/api/v1/plugins/:id` | 获取插件详情 |
| POST | `/api/v1/plugins/:id/enable` | 启用插件 |
| POST | `/api/v1/plugins/:id/disable` | 禁用插件 |
| PUT | `/api/v1/plugins/:id/config` | 更新插件配置 |

### Skills
| 方法 | 路径 | 描述 |
|------|------|------|
| GET | `/api/v1/skills` | 列出 skills |
| GET | `/api/v1/skills/:id` | 获取 skill 详情 |
| POST | `/api/v1/skills/:id/execute` | 执行 skill |
