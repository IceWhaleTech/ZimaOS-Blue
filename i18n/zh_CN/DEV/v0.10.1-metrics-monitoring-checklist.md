# ZimaOS-Echo v0.10.1 指标与监控清单

[English Version](../../../DEV/v0.10.1-metrics-monitoring-checklist.md)

## 概览

v0.10.1 版本聚焦 **Metrics & Monitoring（指标与监控）** —— 为 Echo/Claude Code CLI 提供完整的 API 调用统计、Token 用量追踪、性能指标以及系统/进程资源监控，并通过 InfluxDB 持久化存储和前端仪表盘可视化。

---

## 特性清单

**目标**：实现核心指标数据结构和基础调用统计。

#### 后端 - 指标类型定义
- [x] `Metrics Types`（`server/internal/metrics/types.go`）
