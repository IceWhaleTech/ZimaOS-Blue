# v0.10.2 Claude Code CLI 调用可靠性实现清单

## Phase 1：错误分类与重试 ✅

### 1.1 错误分类器（ErrorClassifier）
- [x] 定义 `ErrorCategory` 类型与常量
- [x] 实现 `ClassifyError()` 函数
- [x] 支持识别：网络错误、超时错误、限流错误、解析错误、配置错误、认证错误
- [ ] 编写单元测试 `error_classifier_test.go`

### 1.2 重试策略（RetryPolicy）
- [x] 定义 `RetryConfig` 结构体
- [x] 实现指数退避 `ExponentialBackoff()`
- [x] 实现线性退避 `LinearBackoff()`
- [x] 实现固定延迟 `FixedDelay()`
- [x] 支持抖动因子（Jitter）
- [ ] 编写单元测试 `retry_test.go`

### 1.3 重试执行器
- [x] 定义并实现 `Retryer` 接口
- [x] 实现 `WithRetry()` 包装（`Do()` 方法）
- [ ] 集成到 `Runner.Run()`（或等价请求执行路径）
