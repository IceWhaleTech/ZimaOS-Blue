# ZimaOS-Echo 路线图

[English Version](../../../DEV/ROADMAP.md)

本文档描述 ZimaOS-Echo 项目的开发方向和里程碑规划。

## 愿景

基于 [clawdbot](https://github.com/clawdbot/clawdbot) 的设计理念，使用 Golang 构建 **NAS 原生 Agent 运行时** —— 轻量、高性能、针对低功耗可信 NAS 设备优化，支持一键部署和单体服务架构。

> **这不是 "Go 版 clawdbot"，而是 "以 clawdbot 为需求样本的 NAS Agent 运行时"。**

## 项目定位

| 特性 | clawdbot (原版) | ZimaOS-Echo (目标) |
|------|----------------|-------------------|
| 语言 | TypeScript/Node.js | Golang |
| 架构 | 多进程/微服务 | 单体 |
| 部署 | 多种方式 | 一键部署 |
| 资源占用 | 高 (Node.js) | 极低 (<80MB) |
| 目标设备 | 通用 | 低功耗 NAS/边缘设备 |
| 前端 | 多种 | Vue 3 |

## 核心原则

1. **稳定优先**：先替换运行时，再添加功能
2. **资源高效**：先控制资源，再追求生态
3. **NAS 原生**：先能常驻，再能扩展
4. **性能优先**：利用 Golang 并发实现高吞吐低延迟
5. **可扩展性**：插件化设计，按需加载功能

## 版本语义

| 版本范围 | 含义 |
|---------|------|
| 0.1 - 0.2 | 技术验证 / 核心稳定 |
| 0.3 - 0.4 | 功能可用 / NAS 集成 |
| 0.5 | 产品级基线（对外发布） |
| 0.6+ | 高级功能 / 生态建设 |

## 阶段规划

### v0.1: Go 运行时核心

**目标**：稳定且长期运行

**必须完成**：
- [x] Go 单进程守护模型
- [x] 主事件循环（显式调度）
- [x] 受控协程 / 工作池
- [x] 全局 Context / 生命周期管理
- [x] 结构化日志 (Zap/Zerolog)
- [x] 基础配置（文件 + 环境变量）使用 Viper
- [x] 健康检查端点
- [x] 基础 HTTP 服务框架

**明确不做**：
- 插件系统
- Skill Hub
- 复杂命令系统
- 前端 UI

**验收标准**：
- [x] 能在 NAS 上运行 **24 小时不重启**
- [x] 空闲 CPU ≈ 0%
- [x] 常驻内存 < 50-80MB

**技术栈**：
- Web 框架：Gin / Fiber / Echo
- 配置：Viper
- 日志：Zap / Zerolog
- 协程池：sourcegraph/conc/pool

---

### v0.2: 核心能力与最小功能

**目标**：能工作，但功能收敛

**新增内容**：
- [x] 核心命令执行框架（静态注册）
- [x] 基础状态管理（KV / 内存 + 持久化）
- [x] 外部 API 调用封装（限流 / 超时）
- [x] 基础指标 API（health / metrics）
- [x] LLM Provider 接口（OpenAI、Claude、Ollama）
- [x] 基础工具/函数调用框架
- [x] 流式响应支持
- [x] 上下文管理
- [x] 记忆/对话历史（SQLite）
- [x] Chat API 端点

**技术重点**：
- 无运行时动态加载
- 无协程泄漏
- 所有 IO 必须可中断

**验收标准**：
- [x] 并发命令可控
- [x] P99 延迟稳定
- [x] 强制 kill 后安全恢复

---

**架构变更**：

**验收标准**：

### v0.4: 插件与扩展模型

**目标**：可扩展但不牺牲性能

**插件策略**（推荐）：
- [x] 编译时插件（Go module）
- [x] JavaScript 插件（goja 运行时，兼容 clawdbot）
- [ ] WASM 插件（能力受限）- 可选
- [x] 插件接口定义
- [x] 插件配置管理
- [x] 插件依赖解析
- [x] 插件隔离与限制

**插件限制**（已实施）：
- 插件不能：
  - 直接访问全局状态
  - 启动协程
  - 绕过调度器
- [x] 每个插件的资源使用限制

**Skill Hub 策略**：
- [x] 不复用 Node Skill Hub
- [x] 新的 Skill Manifest 定义（YAML/JSON）
- [x] Skill 描述与执行分离
- [x] 内置 skills：天气、搜索、计算器、系统信息、日期时间

**安全与身份**：
- [x] 基础认证（JWT）
- [x] 权限控制（RBAC）
- [x] API Key 管理
- [x] API Key 轮换
- [x] 用户角色分配

**前端**：
- [x] 插件管理 UI
- [x] 认证 UI（登录、令牌管理）
- [x] Web 聊天改进（深色模式、移动端适配）
- [x] 系统状态页面
- [x] 备份/恢复 UI

**验收标准**：
- [x] 插件可加载/卸载
- [x] 插件异常不影响主进程
- [x] 性能回退可接受
- [x] 基础认证正常工作
- [x] RBAC 权限已实施
