## 配置

### 新配置选项
```yaml
# v0.5 config.yaml 新增

# 指标
metrics:
  enabled: true
  endpoint: "/metrics"
  include_runtime: true
  include_http: true
  include_llm: true

# 性能分析
profiling:
  enabled: false  # 仅调试时启用
  endpoint_prefix: "/debug/pprof"
  auth_required: true

# 热重载
config:
  hot_reload: true
  watch_interval_ms: 1000
  validate_before_apply: true

# 弹性
resilience:
  circuit_breaker:
    enabled: true
    threshold: 5
    timeout_seconds: 30
  timeout:
    default_ms: 30000
    llm_ms: 120000

# 备份
backup:
  enabled: true
  schedule: "0 2 * * *"  # 每天凌晨 2 点
  retention_days: 7
  path: "./backups"
```

## API 端点（新增）

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | `/metrics` | Prometheus 指标 |
| GET | `/debug/pprof/*` | pprof 性能分析端点 |
| POST | `/api/v1/config/reload` | 触发配置重载 |
| GET | `/api/v1/config/status` | 配置重载状态 |
| POST | `/api/v1/backup` | 创建备份 |
| GET | `/api/v1/backup` | 列出备份 |
| POST | `/api/v1/backup/:id/restore` | 从备份恢复 |
| DELETE | `/api/v1/backup/:id` | 删除备份 |
| GET | `/api/v1/system/health/detailed` | 详细健康检查 |
