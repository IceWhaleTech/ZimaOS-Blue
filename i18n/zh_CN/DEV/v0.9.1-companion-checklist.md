# ZimaOS-Echo v0.9.1 开发清单

[English Version](../../../DEV/v0.9.1-checklist.md)

## 概述

版本 0.9.1 专注于 **Echo Companion** - 一个实时监控工具，为开发者和管理员提供可视化界面来观察跨多平台的 AI Agent 操作。

## 功能清单

### 1. 核心架构和实时事件流 (第一阶段)

**目标**: 建立实时 Agent 活动监控的基础。

#### 后端任务 - 数据模型
- [ ] **会话事件类型** (`server/internal/companion/`)
  - [ ] SessionEvent 结构体，包含 ID、SessionID、Timestamp、EventType、Platform、UserID、TenantID
  - [ ] SessionEventType 常量 (session_start, session_end, message_received, message_sent, tool_call, llm_request, security_threat, sandbox_exec)
  - [ ] MessageEvent 结构体
  - [ ] ToolCallEvent 结构体，包含 ToolName、ToolID、Input、Output、Duration、Status、SandboxUsed、Resources
  - [ ] LLMRequestEvent 结构体
  - [ ] SecurityEvent 结构体，包含 ThreatLevel、ThreatScore、ThreatTypes、DetectedPatterns、Action、FilteredContent
  - [ ] ResourceUsage 结构体，包含 CPUTime、MemoryPeak、IORead、IOWrite

#### 后端任务 - 存储 (JSONL 文件)
- [ ] **基于文件的存储** (`server/internal/companion/storage.go`)
  - [ ] 会话事件的 JSONL 文件写入器
  - [ ] 按日期组织目录 (data/companion/sessions/YYYY-MM-DD/)
  - [ ] 会话文件命名 (session-{id}.jsonl)
  - [ ] 告警日志存储 (data/companion/alerts/YYYY-MM-DD.jsonl)
  - [ ] 每日统计聚合 (data/companion/stats/daily-stats.json)
  - [ ] 文件轮转和清理以满足保留策略

#### 后端任务 - Companion 服务
- [ ] **会话管理器** (`server/internal/companion/manager.go`)
  - [ ] CreateSession - 创建并跟踪新会话
  - [ ] GetSession - 通过 ID 获取会话
  - [ ] ListSessions - 列出会话并支持过滤（平台、用户、时间、状态）
  - [ ] EndSession - 标记会话结束
  - [ ] CleanupExpired - 根据保留策略删除过期会话

- [ ] **事件流处理器** (`server/internal/companion/streamer.go`)
  - [ ] EmitEvent - 向订阅者发送事件
  - [ ] Subscribe - 订阅事件流
  - [ ] Unsubscribe - 取消订阅事件流
  - [ ] 事件缓冲（可配置缓冲区大小）
  - [ ] 批量写入 JSONL 文件（可配置间隔）

#### 后端任务 - WebSocket API
- [ ] **WebSocket 处理器** (`server/internal/companion/websocket.go`)
  - [ ] `ws://host/api/v1/companion/stream` - 所有会话的实时事件流
  - [ ] `ws://host/api/v1/companion/session/:id` - 单个会话的事件流
  - [ ] Ping/pong 心跳（30秒间隔）
  - [ ] 带超时的连接管理
  - [ ] 按订阅参数过滤事件

#### 后端任务 - REST API
- [ ] **REST 处理器** (`server/internal/companion/handler.go`)
  - [ ] `GET /api/v1/companion/sessions` - 获取会话列表并支持过滤
  - [ ] `GET /api/v1/companion/sessions/:id` - 获取会话详情
  - [ ] `GET /api/v1/companion/sessions/:id/events` - 获取会话事件
  - [ ] `GET /api/v1/companion/stats` - 获取统计数据

#### 配置

  - [ ] companion.storage.format (jsonl)
