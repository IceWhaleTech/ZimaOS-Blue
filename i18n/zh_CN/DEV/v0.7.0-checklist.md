# v0.7.0 实施清单

[English Version](../../../DEV/v0.7.0-checklist.md)

本清单跟踪 v0.7.0（安全增强）的实施进度。

## 目标
完成安全机制 - 实现 OIDC 提供者、本地用户管理、密码认证、多因素认证、审计日志和沙箱执行环境。

## 验收标准
- [x] 内置 OIDC 提供者完全可用
- [x] 本地用户管理（CRUD 操作）
- [x] 使用 Argon2id 的密码认证
- [x] 基于 TOTP 的多因素认证可用
- [x] 全面的审计日志系统
- [x] 用于不可信代码的沙箱执行环境
- [ ] 所有安全模块的单元测试
- [ ] 安全文档完成

## 配置

### 新配置选项
```yaml
# config.yaml v0.7 新增内容

# 安全配置
security:
  # OIDC 提供者
  oidc:
    enabled: true
    issuer: "https://your-domain.com"
    signing_key_path: "./keys/oidc.key"
    signing_key_rotation_days: 90
    access_token_ttl: 1h
    refresh_token_ttl: 720h  # 30 天
    authorization_code_ttl: 10m
    clients:
      - client_id: "web-app"
        client_secret: ""  # 公共客户端
        redirect_uris:
          - "http://localhost:3000/callback"
        allowed_scopes:
          - "openid"
          - "profile"
          - "email"

  # 用户管理
  users:
    allow_registration: false
    require_email_verification: false
    default_role: "user"

  # 密码策略
  password:
    min_length: 12
    require_uppercase: true
    require_lowercase: true
    require_number: true
    require_special: true
    history_count: 5
    expiration_days: 0  # 0 = 永不过期
    lockout_threshold: 5
    lockout_duration: 15m

  # MFA
  mfa:
    enabled: true
    required: false  # 要求所有用户使用 MFA
    issuer: "ZimaOS-Echo"
    recovery_codes_count: 8

  # 审计
  audit:
    enabled: true
    retention_days: 90
    log_request_body: false
    log_response_body: false
    excluded_paths:
      - "/health"
      - "/metrics"

  # 沙箱
  sandbox:
    enabled: true
    default_timeout: 30s
    max_timeout: 5m
    memory_limit: 256MB
    cpu_limit: 1.0  # 1 个 CPU 核心
    process_limit: 10
    network_enabled: false
```

## 安全考虑

1. **密码存储**：使用具有安全参数的 Argon2id
2. **令牌安全**：短期访问令牌，安全的刷新令牌轮换
3. **MFA 安全**：限制 TOTP 尝试速率，安全的恢复代码
4. **OIDC 安全**：需要 PKCE，严格的重定向 URI 验证
5. **审计完整性**：仅追加日志，篡改检测
6. **沙箱安全**：深度防御，最小权限
